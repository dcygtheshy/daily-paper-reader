## 摘要
大语言模型（LLM）水印提供了一种轻量级机制，用于识别由特定模型生成的文本，但其鲁棒性在后处理攻击下仍然脆弱。删除攻击尤其具有挑战性，因为它们会改变 token 位置，并破坏观测 token 与其原始水印位置之间的对齐。我们提出 Reed--Muller 码水印（RMCW），一种基于 Reed--Muller 码的 LLM 水印方法。与全局码字恢复不同，RMCW 搜索存活的局部代数结构，利用 Reed--Muller 码字的仿射线限制所诱导的 Reed--Solomon 一致性。在生成过程中，RMCW 通过秘密密钥的词表划分将 Reed--Muller 结构注入序列。在检测过程中，它将给定文本映射到带密钥的词表桶，并使用 Berlekamp--Welch 检验来测试局部子序列的低次 Reed--Solomon 一致性。在 C4 和 ELI5 数据集上，使用 OPT-1.3B 和 Llama-3.1-8B-Instruct 进行的实验表明，RMCW 保持了较强的干净文本可检测性，并在多种删除和改写攻击下优于或匹配基线方法。我们的代码可在 https://github.com/BaichengDanny/RMCW 获取。

## Abstract
Large Language Model (LLM) watermarking provides a lightweight mechanism for identifying text generated by a specific model, but its robustness remains fragile under post-processing attacks. Deletion attacks are particularly challenging because they shift token positions and break the alignment between observed tokens and their original watermark positions. We propose Reed--Muller Code Watermarking (RMCW), an LLM watermarking method based on Reed--Muller codes. In contrast to global codeword recovery, RMCW searches for surviving local algebraic structure, leveraging the Reed--Solomon consistency induced by affine-line restrictions of Reed--Muller codewords. During generation, RMCW injects a Reed--Muller structure into the sequence via a secret-keyed vocabulary partition. During detection, it maps the given text to keyed vocabulary bins and tests local subsequences for low-degree Reed--Solomon consistency using Berlekamp--Welch tests. Experiments on C4 and ELI5 datasets with OPT-1.3B and Llama-3.1-8B-Instruct show that RMCW preserves strong clean-text detectability and outperforms or matches the baseline methods under several deletion and rewriting attacks. Our code is available at https://github.com/BaichengDanny/RMCW.

# RMCW 论文中文总结

## 1. 核心问题与研究动机

- **背景**：LLM 水印通过在生成阶段注入隐藏信号，使检测方能够判断一段文本是否由特定模型生成。实用水印需同时满足三点：少量文本即可检测、不显著损害生成质量、能抵抗常见后处理操作。
- **核心痛点——删除攻击**：基于纠错码（ECC）的水印把编码信号绑定到生成位置。一旦文本被删除（裁剪、截断、部分转载等），后续所有 token 的位置都会前移，导致观测符号与原始水印位置失去对齐。作者将这一问题命名为 **同步丢失（synchronization loss）**，并指出它是位置对齐式编码水印的核心障碍。
- **关键观察**：对于零比特水印，**检测比完整码字恢复更弱**——检测器只需在观测序列中找到一种"在水印文本中才可能出现的结构"，而不必恢复原始码字。因此作者把问题从"全局码字恢复"重构为"局部结构检验"。
- **整体含义**：RMCW 将 Reed–Muller（RM）码的仿射线代数性质引入 LLM 水印，使检测器能在位置错乱后仍从残存的局部子序列中找到 Reed–Solomon（RS）一致性证据，为删除鲁棒水印提供了编码理论新思路。

## 2. 方法论

### 核心思想
- RM 码字限制在任意仿射线上会退化为一个低次一元多项式，即一个 **RS 码字**。因此一个 RM 网格内部天然包含大量可局部检验的低次代数结构。删除只会减少可观测坐标数量，而不必破坏这些局部结构。

### 生成流程（Algorithm 1）
1. **密钥词表划分**：用秘密密钥 $K_{\text{bin}}$ 通过 HMAC 把词表 $V$ 映射到 $q$ 个 bin：$\hat{b}_{K_{\text{bin}}}(v)=\mathrm{HMAC}(K_{\text{bin}},v)\bmod q\in\mathbb{F}_q$。
2. **RM 符号构造**：由载荷种子 $s_{\text{payload}}$ 伪随机展开为 $\mathbb{F}_q[u,v]$ 上总次数 $\le d$ 的二元多项式 $f_{\text{pay}}$ 的系数，在 $\mathbb{F}_q^2$ 上求值得到 $q\times q$ 网格 $C_{\text{pay}}$，按行主序序列化为 $A_{\text{pay}}=(a_0,\dots,a_{q^2-1})$。第 $t$ 步的目标符号为 $a_t=A_{\text{pay}}[t\bmod q^2]$。
3. **logit 偏置注入**：$\tilde{\ell}_t(v)=\ell_t(v)+\delta\cdot\mathbf{1}\{\hat{b}_{K_{\text{bin}}}(v)=a_t\}$，即提高属于目标 bin 的 token 的 logits，再从 $\mathrm{softmax}(\tilde{\ell}_t)$ 采样。基础模型保持冻结，属标准 logits 式水印范式。

### 检测流程（Algorithm 2）
1. **token → 符号**：用同一密钥划分把待检文本映射为符号序列 $\hat{A}=(\hat{a}_1,\dots,\hat{a}_n)$。
2. **局部一致性检验**：对起始索引 $s$、步长 $\tau$、窗口长度 $m$ 定义窗口 $W(s,\tau)=(\hat{a}_s,\hat{a}_{s+\tau},\dots,\hat{a}_{s+(m-1)\tau})$，检验其是否在容错 $e$ 内与某个次数 $\le d$ 的一元多项式一致；用 **Berlekamp–Welch 解码 + 显式距离验证**实现。$e=0$ 为精确 RS 一致性，$e>0$ 容忍替换或 bin 错配。
3. **自适应步长选择**：候选步长集合 $T=\{1,\dots,\lfloor (n-1)/(m-1)\rfloor\}$，先用 $N_{\text{pilot}}$ 次试点试验打分，保留至多 $k$ 个最优步长 $R\subseteq T$，以适配未知的删除模式。
4. **统计判决**：对每个 $\tau\in R$ 采样 $N_{\text{trials}}$ 个窗口，记成功数 $X_\tau$，用步长专属零假设成功率 $\pi_{0,\tau}$ 计算二项尾概率 $p_\tau$；再用 Bonferroni 校正聚合 $p_{\det}=\min\{1,|R|\cdot\min_{\tau\in R}p_\tau\}$，$p_{\det}\le\alpha$ 则判定为水印文本。

### 理论分析
- **命题 1（Berlekamp–Welch）**：若接收值相对某低次多项式最多错 $e$ 个坐标且 $2e<m-d$，可多项式时间唯一恢复该多项式。
- **定理 1（替换界）**：给出噪声水印分布接受概率 $P^{\text{wm}}_{\text{acc}}=\sum_{i=0}^{e}\binom{m}{i}\rho^i(1-\rho)^{m-i}$ 与零分布接受概率 $P^{\text{null}}_{\text{acc}}=\frac{\sum_{i=0}^{e}\binom{m}{i}(q-1)^i}{q^{m-d-1}}$，当 $0.99\,P^{\text{wm}}_{\text{acc}}>P^{\text{null}}_{\text{acc}}$ 时两个分布可以常数优势区分。

### 关键参数
- $q=17$，$d=3$，$m=12$，$e=2$，$\delta=5$；检测端 500 次试点试验，最多保留 8 个步长。
