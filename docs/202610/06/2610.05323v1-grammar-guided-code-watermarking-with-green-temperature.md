## 摘要
大语言模型水印在解码过程中嵌入可检测的统计信号，但由此带来的词元概率变化可能会降低生成质量。这种权衡对代码尤为重要，因为词元选择上的微小变化就可能破坏语法或改变程序行为。现有的代码水印方法通过基于熵的插入或语法感知的词元选择来缓解这一风险，但它们并未直接在当前语法状态所允许的延续集合上构造水印。我们提出语法引导的绿色温度代码水印（GTCW），它将语法约束解码与概率感知水印相结合。在每个解码步骤，GTCW 将候选集限制为语法允许的词元，并将该支持集划分为带密钥的绿色子集和红色子集。在符合条件的高熵位置，绿色温度根据模型的相对偏好对绿色词元重新加权，在保留语法约束的同时增强水印信号。在涵盖四种编程语言的五个模型和五个基准上，GTCW 的平均 AUROC 达到 73.61%，而最强基线为 67.83%；同时平均 Pass@1 为 59.18%，未加水印生成为 59.58%。我们的实现见 https://github.com/hyundong98/GTCW。

## Abstract
Large language model watermarking embeds detectable statistical signals during decoding, but the resulting changes to token probabilities can degrade generation quality. This trade-off is particularly important for code, where small changes in token selection can break syntax or alter program behavior. Existing code watermarking methods mitigate this risk through entropy-based insertion or syntax-aware token selection, but they do not directly construct the watermark over the set of continuations admitted by the current grammar state. We propose Grammar-Guided Code Watermarking with Green Temperature (GTCW), which integrates grammar-constrained decoding with probability-aware watermarking. At each decoding step, GTCW restricts the candidate set to grammar-admissible tokens and partitions this support into keyed green and red subsets. At eligible high-entropy positions, green temperature reweights the green tokens according to the model's relative preferences, strengthening the watermark signal while retaining the grammar constraint. Across five models and five benchmarks spanning four programming languages, GTCW achieves a mean AUROC of 73.61%, compared with 67.83% for the strongest baseline, while maintaining a mean Pass@1 of 59.18% versus 59.58% for unwatermarked generation. Our implementation is available at https://github.com/hyundong98/GTCW .
