## 摘要
水印通过解码过程中嵌入可统计检测的信号来追踪大型语言模型生成文本的来源。现有方案分为基于logits、基于采样、熵感知和自适应强度等类别，但它们都根据局部词元统计来放置水印信号。在本工作评估的开放式文本生成设置中，局部统计可能无法为放置稳健的水印信号提供足够指导。我们提出WorldMark，一个即插即用接口，使用世界知识记忆（WKM）在记忆图中组织语义和情景知识，将检索到的知识转换为词元级知识显著性分数，并通过非对称知识调制（AKM）调整宿主水印的强度。WorldMark无需对主干模型进行重训练，也不引入额外的检测端模型或参数。在主要C4评估中，完整的WorldMark接口在三种自适应强度宿主变体上提高了干净和攻击检测性能，同时略微降低了困惑度。在C4和OpenGen上的额外试点实验表明，直接记忆条件化可跨多种水印族迁移，但在缺乏显著性感知调制时可能不稳定。WorldMark无需额外的检测端模型或参数，并在主要协议下引入可忽略的开销。

## Abstract
Watermarking traces the provenance of text produced by large language models by embedding statistically detectable signals during decoding. Existing schemes fall into logits-based, sampling-based, entropy-aware, and adaptive-strength families, yet all of them place watermark signals according to local token statistics. In the open-ended text-generation settings evaluated in this work, local statistics may provide insufficient guidance for placing robust watermark signals. We introduce WorldMark, a plug-and-play interface that uses World Knowledge Memory (WKM) to organize semantic and episodic knowledge in a memory graph, converts the retrieved knowledge into a token-level knowledge saliency score, and adjusts the strength of a host watermark through Asymmetric Knowledge Modulation (AKM). WorldMark requires no backbone retraining and introduces no additional detector-side model or parameter. On the primary C4 evaluation, the complete WorldMark interface improves clean and attacked detection across three adaptive-strength host variants while slightly reducing perplexity. Additional pilot experiments on C4 and OpenGen show that direct memory conditioning transfers across multiple watermark families but can be unstable without saliency-aware modulation. WorldMark requires no additional detector-side model or parameter and introduces negligible overhead under the primary protocol.

## 1. 论文的核心问题与整体含义

- **背景与动机**：大型语言模型（LLM）的大规模生成使得文本溯源与问责成为必需，水印技术因此成为主要机制。现有水印方法可分为四类：基于 logits（绿色表偏置）、基于采样（伪随机序列）、熵感知（仅在高熵位置加水印）、自适应强度（按质量目标逐 token 调强度）。这些方法均假设“在何处以及以多强加水印”可以仅由局部信息（如 token logits 或前缀哈希）决定。
- **核心问题**：在知识密集型开放文本生成场景中，承载知识的关键 token（实体、关系、标识符）的正确性由外部知识决定，而非局部不确定性。局部统计要么因为这类 token 熵低而标记过弱，要么把信号放在容易被释义攻击移除的位置，从而缺乏“知识显著性”（knowledge saliency）这一放置信号。
- **总体含义**：论文提出 WorldMark，一个即插即用接口，通过世界知识记忆（WKM）将语义与情景知识组织成记忆图，检索并转换为 token 级知识显著性分数，再通过非对称知识调制（AKM）调整宿主水印强度。目标是让水印信号被放置在“既安全又难以被攻击者改写”的知识锚定 token 上，同时不重训主干模型、不增加任何检测端模型或参数。

## 2. 论文提出的方法论

### 2.1 核心思想
- 将水印放置从“局部 token 统计驱动”升级为“全局知识显著性驱动”。
- WorldMark 与宿主水印解耦，只需将知识显著性分数 st 和复合调制因子 μt 提供给宿主水印即可，不改变原有检测器。

### 2.2 三个功能组件

1. **World Knowledge Memory（WKM）**
   - 维护记忆图 G = (Vs, Es, Ve, Ee)，其中 Vs/Es 为语义记忆（事实三元组），Ve/Ee 为情景记忆（支持该事实的观测记录）。
   - 在生成开始时构建查询 q0 = enc((x, y_obs))，从图中检索语义三元组 EQs 与 k 个情景顶点 VQe。
   - 语义搜索用余弦相似度（基于 Sentence-BERT 对序列化三元组文本的嵌入），情景顶点支持度由 ni / max(Ni,1) 的加权公式衡量。
   - 检索结果序列化为固定知识上下文 c0，截断到 512 token；只在每个 episode 开始构建一次，不逐 token 重新检索，以控制开销。

2. **Knowledge Saliency Estimator（知识显著性估计器）**
   - 对解码步 t，计算知识显著性分数：st = σ(λ · sim(ϕ(c0), ϕ(top_m(pkt)))) ∈ [0,1]。
   - ϕ(·) 为 all-MiniLM-L6-v2 句子编码器；top_m(pkt) 取当前知识条件化分布下概率最高的 m=20 个 token 的表面字符串拼接编码。
   - 虽然 c0 固定，但 st 会随前缀 y<t 变化，因此产生位置相关的调制，且无需未来 token 信息。
   - st 被定位为“候选分布与检索知识上下文的软对齐程度”，不是事实性判断。

3. **Asymmetric Knowledge Modulation（AKM）**
   - 产生两个不对称系数：
     - 质量缓解系数 ρt = 1 − βp·st（对知识锚定 token 降低扰动）；
     - 检测增强系数 ηt = 1 + βd·(1 − st)（对弱锚定 token 增强信号）。
   - 复合因子 μt = ρt·ηt，用于调制宿主水印强度。
   - 对自适应 logits 水印，用 ert = clip(μt·ϕ(PG), ϵ, 1−ϵ) 替代原强度，并按绿/红表注入概率；对采样类水印，用 (pki)^μt 归一化后做指数最小采样；对混合共生方案，用 st 移动熵门控阈值 αt、βt。

### 2.3 即插即用性
- 仅修改生成接口（知识上下文 c0、显著性 st、调制强度 ert），不引入额外检测端模型/参数，不重训主干，保持原宿主检测器不变。

## 3. 实验设计

### 3.1 数据集与场景
- **主要实验**：C4 数据集，生成模型 OPT-1.3B，困惑度评估用 LLaMA2-7B。400 条续写，30 token 提示前缀，生成 200–230 token。
- **扩展实验（附录 A）**：LLaMA-3-8B、Mistral-7B 作为生成骨干；TriviaQA、NaturalQuestions 作为知识密集型基准。
- **跨族试点（附录 B/C）**：C4 和 OpenGen 两个数据集，7 个宿主水印（KGW、EWD、SWEET、EXP、Series、Parallel、Hybrid），规模为 12 样本、25 token（试点）；另有 N=500、五 seeds 的扩展评估。

### 3.2 对比方法
- 传统/现有方法：KGW、UW、DiPmark、SWEET、EWD。
- 主攻宿主：MorphMark 的 exponential、linear、log 三种变体。
- 对比配置：Paper（原论文报告值）、Repro（作者复现值）、+WorldMark（完整接口）；试点中还比较 Baseline vs +WKM（untuned，直接 prompt 级注入，无 AKM）。

### 3.3 攻击与指标
- 攻击：Word-S（30% 词替换为 WordNet 同义词）用于主要评估；Word-D（随机删词）用于跨族试点。
- 指标：TPR@1%FPR、Best F1、鲁棒 TPR/F1、PPL、生成延迟、检测延迟；试点还用 TNR、AUROC、困惑度。

## 4. 资源与算力

- 主要实验使用 **NVIDIA A6000 GPU**，CUDA 12.1，批次大小为 1。
- Sentence-BERT 编解码器（all-MiniLM-L6-v2，22.7M 参数）与语言模型同 GPU 异步执行；单次前向约 1.2–1.5 ms。
- 论文仅声称在“该配置下未观察到可测量的延迟惩罚”，并说明其他硬件/更大模型下开销可能显现。
- 论文**未给出训练时长或 GPU 数量**等更详细的算力统计；只报告了生成/检测延迟（如 MorphMark-linear +WorldMark 生成 1.8530s，检测 29.33ms）。

## 5. 实验数量与充分性

- **主要实验**：3 个 MorphMark 变体 × 多指标，5 个随机种子（0–4），400 条 continuation；有消融（附录 E，8 种配置）、扩展骨干（2 个新模型）、知识密集型数据集（2 个）、跨族扩展（N=500，5 seeds）。

## 6. 论文的主要结论与发现

- 完整的 WorldMark 接口在 C4 上对三种 MorphMark 变体均一致改善干净检测、攻击检测和困惑度：平均鲁棒 TPR 提升 0.0296，鲁棒 F1 提升 0.0108，PPL 平均下降 0.0312。
- 最大获益来自检测增强项（boost），即将水印信号重新分配到知识锚定较弱的 token 上，从而在释义攻击下保留水印余量。
- 直接记忆注入（+WKM untuned）并不稳定：在试点中对部分宿主（如 KGW）保持饱和，但会大幅降低 EXP、Parallel 等宿主的 F1 并推高 PPL，说明“仅有结构知识不够”，需要显著性感知的 AKM 进行受控调制。
- 扩展实验显示，知识显著性估计器能泛化到 LLaMA-3-8B、Mistral-7B 以及 TriviaQA/NaturalQuestions，且知识密集场景中收益更大。
- WorldMark 不引入额外检测端模型或参数，生成/检测延迟基本不变。

## 7. 优点

- **新颖的问题定义**：首次系统研究“知识显著性”作为跨异构宿主水印的共享放置信号，切入点在现有文献中较新。
- **即插即用设计**：不重训主干、不改检测器，只通过知识上下文+显著性+AKM 调制宿主强度，兼容 logits、采样、熵门控、自适应强度等四类水印，架构上轻量。
- **质量与检测双赢**：通过非对称调制（对锚定 token 保护、对非锚定 token 增强）同时降低 PPL 并提升鲁棒检测，克服了传统质量-检测权衡。
- **实验规范性**：主实验有复现基线、多种宿主变体、消融、统计检验、不同骨干和数据集，附录提供了完整的超参搜索、F1 阈值选择协议和种子明细。
- **负对照有价值**：跨族试点关于“无调制知识注入不稳定”的分析，反而强化了完整方法模块设计的必要性，逻辑自洽。

## 8. 不足与局限

- **攻击覆盖有限**：仅评估词级同义词替换和随机删除，未覆盖更强的 LLM 改写、翻译往返、混合复制粘贴或针对性事实替换，鲁棒性结论的泛化能力存疑。
- **跨族试点规模过小**：12 样本、25 token 的试点只能算探索性/负对照，难以给出跨族改进的可靠统计结论；作者也承认这一点。
- **知识记忆的构建依赖 LLaMA-3-8B 抽取事实**：无法保证抽取正确性，且实体对齐仅用大小写不敏感的精确匹配，未做实体链接，可能在复杂开放域场景中引入噪声。
- **开销声明有条件性**：仅在批大小 1、A6000 且 Sentence-BERT 与 LM 异步执行时“无延迟惩罚”，对更大模型、显存受限或 CPU 部署场景，开销未验证。
- **检测端无参但生成端有额外计算**：每个解码步需一次 Sentence-BERT 前向（top-m 编码），虽然文中称被 GPU 并行掩盖，但仍是一个潜在瓶颈。
- **调参依赖小验证集**：λ、m、βp、βd 等仅用 50 个 C4 样本调优，可能过拟合到该数据分布，跨域泛化有待更多基准验证。
- **部分比较较弱**：Table 1 中“Paper”值与“Repro”值存在明显差距（如 UW、DiPmark），作者以 Repro 为准，但未能给出原论文复现偏差的具体原因，可能影响公平性讨论。
