## 摘要
黑盒LLM服务已成为一种实用的部署范式。然而，其不透明性也阻碍了安全风险的系统性评估，并使模型所有者的版权审计复杂化。黑盒LLM指纹识别通过查询-响应交互来识别底层LLM身份，为弥合这一差距提供了一种有前景的方法。现有方法通常使用固定查询集从目标LLM服务收集响应，在现实复杂配置（如系统提示和采样设置）下表现不佳。为克服这些限制，我们提出AdaptPrint，一种用于在黑盒LLM服务中揭示隐藏LLM身份的响应自适应指纹识别方法。AdaptPrint集成了三种渐进式响应一致性探测策略：直接探测、续写探测和后续探测。AdaptPrint通过对候选LLM进行相似度匹配来确定最终LLM身份。实验结果表明，在27个候选模型中，AdaptPrint显著优于最先进方法，Top-1、Top-3和Top-5准确率分别达到80.6%、90.3%和92.1%。AdaptPrint在不同防御策略和解码参数下也表现出强鲁棒性。

## Abstract
Black-box LLM services have emerged as a practical deployment paradigm. Nevertheless, their opacity also hinders the systematic assessment of security risks and complicates copyright auditing for model owners. Black-box LLM fingerprinting, which identifies the underlying LLM identity through query-response interactions, offers a promising way to bridge this gap. Existing approaches typically collect responses from target LLM services using a fixed set of queries and perform poorly in the presence of realistic and complex configurations (e.g., system prompt and sampling settings). To overcome these limitations, we propose AdaptPrint, a response-adaptive fingerprinting method for revealing hidden LLM identities in black-box LLM services. AdaptPrint integrates three progressive response consistency probing strategies: Direct Probing, Continuation Probing, and Follow-up Probing. AdaptPrint determines the final LLM identity by performing similarity matching among candidate LLMs. Experimental results show that AdaptPrint significantly outperforms state-of-the-art methods among 27 candidate models, achieving Top-1, Top-3, and Top-5 accuracies of 80.6%, 90.3%, and 92.1%. AdaptPrint also demonstrates strong robustness across different defense strategies and decoding parameters.

## 1. 论文的核心问题与整体含义

- **研究背景**：大语言模型（LLM）被广泛部署为黑盒服务，用户只能通过 API 或网页接口查询，无法访问模型参数与权重。部分服务商出于升级灵活性、降低攻击暴露面等考虑，不公开底层模型身份，形成“黑盒 LLM 服务”。
- **核心问题**：
  - 安全评估困难：黑盒服务可能被攻击者利用已知模型漏洞发起自适应攻击，但服务方和审计方却难以获知真实模型身份。
  - 版权审计困难：恶意服务商可能绕过许可证限制部署模型，模型所有者无法有效追溯。
- **现有不足**：
  - 已有指纹识别方法（MET、LLMmap、ZeroPrint）大多依赖固定查询集；
  - 固定查询在复杂系统提示、采样设置、防御过滤等现实配置下容易失效；
  - 现有方法隐含假设“同一模型在任意配置下行为一致”，但该假设在系统提示很长或解码参数变化时难以成立。
- **论文主张**：指纹识别应从目标模型自身的响应出发（response-adaptive），而不是从固定查询出发。AdaptPrint 通过响应自适应探测来识别黑盒 LLM 身份，可用于安全风险评估和版权审计。

## 2. 方法论

**核心思想**：

- 用目标模型自己的响应作为“锚点”，构造探测输入，再与候选模型池中的模型行为进行一致性比较。
- 将底层假设从  
  φ(llm_black, q) ≈ φ(llm_white, q)  
  转变为  
  r* = llm_black(q*)，φ(llm_black, r*) ≈ φ(llm_white, r*)。  
  即：指纹分析基于目标模型实际产生的响应，而不是预设查询。

**整体流程（四阶段）**：

1. **初始问题生成**：使用辅助 LLM（Gemini-3-Flash-Preview）按目标服务领域生成“低熵但非平凡”的开放问题，要求答案沿单一稳定解释主干（如约束消解路径、决策路径）展开，既降低随机性又保留模型特异性。
2. **候选模型池构建**：将 27 个已知身份的 LLM 放在统一系统提示（“You are a helpful assistant.”）和低随机解码设置（temperature/top-p = 0.0/1.0）下查询，作为比较基准。
3. **多策略指纹收集**：集成三种响应一致性探测策略：
   - **Direct Probing（直接探测）**：用相同初始问题询问目标模型和所有候选模型，直接比较响应相似度。
   - **Continuation Probing（续写探测）**：取目标响应的中间位置（通过 Algorithm 1 选择低 next-token 熵的起点），让候选模型从此处续写，再与后半段真实响应比较。三个不同聚类起点各生成一条续写，最终保留得分最高的两分支。
   - **Follow-up Probing（后续探测）**：基于目标响应生成一个连贯的后续问题，并附上“问题-响应”上下文，让目标模型和候选模型回答，再进行相似度比较。
4. **指纹匹配（Algorithm 2）**：
   - 分别计算语义相似度（嵌入模型 cosine 相似度，使用 Qwen3-4B-Embedding）和文本相似度（n-gram Jaccard）；
   - 按策略权重（Direct/Continuation/Follow-up 各 0.25）、语义/文本权重各 0.5 聚合得分；
   - 总分最高者为推断身份；开放集场景下用 top-1 与 top-2 的差距阈值 τ 判定是否拒绝为“未知模型”。

**关键公式**：

- Jaccard_n(x, y) = |G_n(x) ∩ G_n(y)| / |G_n(x) ∪ G_n(y)|
- 匹配目标：m̂ = arg max_m Agg_{τ∈T} [Sim(r_B^τ, r_{C_m,τ})]

**关键技术细节（Algorithm 1）**：

- 用本地开源 LLM（Qwen-3-8B）计算每个 token 位置 top-1 logit 与 top-2 logit 的乘积作为置信度；
- 剔除前后 25% 边界 token，按窗口大小 10 做滑动平均；
- 对候选位置按得分降序排序后 KMeans 聚类为 3 组，每组取最高分位置作为续写起点，兼顾稳定性与多样性。

## 6. 主要结论与发现

- AdaptPrint 在 27 个候选模型上获得 Top-1 80.6%、Top-3 90.3%、Top-5 92.1%（AdaptPrint-Triple），比最强基线 ZeroPrint 在 Method-Gen 下分别提升 32.5、21.3、15.2 个百分点。
- 三种探测策略互补：各自 Top-1 在 61.6%–67.6%，两两组合达 73.6%–75.9%，三者联合 80.6%，明显优于任何子集。
- 输入侧防御实验表明：LLMmap 大量触发安全拒绝（如 Off-Topic 133/144），ZeroPrint 与 MET 也被拒或离题；AdaptPrint 生成的 54 个初始问题仅 3 个被判离题，说明自适应问题生成能有效规避防御。
- 输出侧防御下约 1% 响应被标记为风险，多为医疗/健身领域内容，非显式有害。
- 对解码随机性鲁棒：六组温度/top-p 下正确识别数稳定在 9–11/12。
- 开放集验证可行：通过 top1–top2 分数差距阈值可权衡已知接受与未知拒绝，τ 在 0.010–0.0125 附近平衡较好。
- 微调模型可追溯：12 个微调设置中 Top-1/Top-3/Top-5 分别识别 8/9/11 个，能将 LoRA 微调模型回溯到基座模型。

## 7. 优点

- **视角新颖**：从“固定查询”转向“响应自适应”，将模型自身输出作为指纹锚点，理论假设更贴近现实配置变化。
- **策略设计具有互补性**：直接探测捕获整体语义一致性、续写探测约束于模型自身的 next-token 轨迹、后续探测利用较长的上下文前缀，三者从不同粒度验证同一响应，形成渐进式多维匹配。
- **续写起点选择有理论支撑**：基于低熵 token 位置选择起点，并用聚类保证多样性，避免随机起点不稳定。
- **防御规避能力强**：自适应良性、领域相关问题可绕过 prompt 注入/越狱/离题检测，而无需依赖固定问题库。
- **成本低**：每个目标仅约 $0.044，且不依赖白盒信息，易于落地。
- **鲁棒性验证充分**：覆盖多种解码参数、系统提示、防御机制、开放集与微调场景，结论可信度高。
- **对开放集和版权追溯给出实用方案**，扩展了闭集分类之外的应用能力。

## 8. 不足与局限

- **依赖初始问题质量**：不同初始问题会导致同一服务不同识别结果；问题生成依赖辅助 LLM（Gemini-3-Flash-Preview），如果辅助模型本身存在偏差，可能影响指纹质量。论文建议后续用强化学习做系统化探测优化。
- **假设目标模型在交互窗口内稳定**：不支持动态多模型路由服务；如果同一会话内不同请求被路由到不同子模型，指纹可靠性会下降。
- **相似度指标非普适**：Jaccard 对长响应模型（如 mimo-v2.5）存在长度惩罚；改用 containment 指标虽能缓解，但会降低其他模型的整体表现，尚未找到对所有模型一致的指标。
- **实验规模局限**：黑盒目标仅 12 个且由作者挑选，未覆盖所有 27 个模型作为目标的全部组合；真实服务案例仅 1 个，代表性有限。
- **缺乏端到端动态防御评估**：输出侧防御下的风险标记率统计较粗略，未详述标记内容与误判率。
- **开放集阈值的通用性**：τ 需要针对不同服务调节，论文未给出自适应阈值选择规则，实际部署时可能需要人工标定。
- **未见与更常见“真实黑盒 API”的对比**（如 Azure OpenAI、AWS Bedrock 等），目前实验集中于 OpenRouter 平台，平台内部配置未知可能带来偏差。
