## 摘要
隐形图像水印越来越多地用于深度伪造检测和来源追踪，它们不仅需要承受偶然失真，还要抵御蓄意去除。我们在现代神经后处理水印架构内重新审视了扩频嵌入这一经典水印原理。我们的起点是一个测量：在现有的编码器-解码器方案中，每个消息比特仅占据图像的一小部分，这是导致其脆弱性的一个共同因素，因为去除只需扰动该比特所占据的区域即可。SpreadMark则相反，它将每个比特作为密集的伪随机码字扩展到整个图像，并通过匹配滤波学习到的覆盖抑制码片表示来恢复，同时采用并行卷积解码路径和稀疏化感知训练。条件码片空间分析表明，在码字无关扰动模型下，密集扩展增加了破坏匹配滤波恢复所需的预算。在COCO和DIV2K上与九种方案的对比评估中，SpreadMark是唯一在我们测试的再生和潜空间稀疏化设置下均保持高检测率的方法，同时具有竞争力的JPEG和加性噪声鲁棒性。它保持嵌入的水印不可感知，在COCO和DIV2K上均维持了高感知质量。

## Abstract
Invisible image watermarks are increasingly used for deepfake detection and provenance tracking, where they must survive not only incidental distortions but also deliberate removal. We revisit spread-spectrum embedding, a classical watermarking principle, inside a modern neural post-hoc watermarking architecture. Our starting point is a measurement: in existing encoder-decoder schemes each message bit occupies only a small fraction of the image, a shared contributing factor to their fragility, since removal then need only disturb the region a bit occupies. SpreadMark instead spreads each bit as a dense pseudo-random codeword over the whole image and recovers it by matched-filtering a learned cover-suppressed chip representation, with a parallel convolutional decoding path and sparsification-aware training. A conditional chip-space analysis shows that, under a codeword-independent perturbation model, dense spreading increases the budget required to disrupt matched-filter recovery. Evaluated on COCO and DIV2K against nine schemes, SpreadMark is the only evaluated method retaining high detection under both the regeneration and the latent-space sparsification settings we test, with competitive JPEG and additive-noise robustness. It keeps the embedded watermark imperceptible, maintaining high perceptual quality on both COCO and DIV2K.

- **核心观察与问题**：论文通过实验测量发现，现有编码器-解码器水印方案（如HiDDeN、StegaStamp等）存在一个共同的结构性弱点——每个消息比特仅占据图像的极小区域（即"per-bit footprint"很小）。这意味着攻击者只需扰动该比特所在的小块区域即可抹除水印信息，导致水印整体脆弱。
- **核心思想**：借鉴经典的扩频通信原理（spread-spectrum），将每个比特的信息散布到整幅图像上，使攻击者需要极大的扰动预算才能破坏水印恢复。
- **整体含义**：这项工作表明，经典的扩频机制经过现代神经网络架构的改造，可以显著提升水印在多种攻击下的鲁棒性，为深伪检测与溯源提供了更可靠的方案。

## 2. 方法论：核心思想、关键技术细节

### 2.1 核心设计

SpreadMark 在经典的 HiDDeN 加性残差架构基础上，引入并行扩频嵌入机制。整体框架包含：

- **编码器**：将 K 位消息 b 嵌入覆盖图像 x，产生视觉上接近原图的水印图像 x_w，由两部分叠加而成：
  1. 学习得到的 CNN 残差 g_θ(x, b)（遵循 HiDDeN 的加性残差设计）；
  2. 显式的扩频信号 s(b)：每个比特分配一个固定的伪随机码字 c_i，消息以所选码字的叠加形式嵌入。

### 2.2 扩频嵌入公式

水印图像的生成公式为：

```
x_w = Π(x + g_θ(x, b) + α · (1/√K) · Σ(2b_i − 1)c_i)
```

- 码字 c_i 为单通道图，零均值、单位逐像素方差，为 i.i.d. 高斯随机变量，不同码字之间近似正交；
- 因子 1/√K 使扩频信号 s(b) 的逐像素方差与负载无关；
- α 是学习得到的每像素振幅（softplus 参数化），控制比特恢复与视觉质量之间的权衡。

### 2.3 解码器：匹配滤波 + 卷积头 + 逐比特门控

解码器由两条路径组成：

- **匹配滤波路径**：通过全卷积骨干网络提取特征 ψ(x′)，经 1×1 投影 W 得到单通道"码片"图 ẑ（cover-suppressed chip），然后与同一码字库进行归一化相关运算，得到统计量 ρ_i = ⟨ẑ, c_i⟩/d。
- **卷积解码路径**：通过全局平均池化（GAP）和线性映射得到 h(x′)，作为固定空间码失同步时的备用路径。
- **逐比特门控**：门控值 γ_i = σ(Lin_γ(GAP(ψ(x′))))_i 用于加权匹配滤波项，最终的比特估计为：
  ```
  b̂_i = σ(h_i(x′) + γ_i(a_i·ρ_i + β_i))
  ```

### 2.4 稀疏化感知对抗训练（SA-AT）

- 对四种攻击类型，仅标准失真通过训练增强应对（JPEG压缩、模糊、噪声、亮度、裁剪缩放）；
- 稀疏化攻击单独通过一个 SA-AT 阶段模拟：将图像深度特征投影到低秩子空间，采样秩 r ∈ [4, 32]，执行 T=3 步像素空间梯度步骤；
- 用于评估的代理攻击是独立构建的，鲁棒性并非来自匹配特定攻击者。
- 总损失函数为：
  ```
  L = λ_a·ℓ(D(A(x_w))) + λ_b·ℓ(D(x_w)) + λ_h·ℓ(h(A(x_w))) + λ_v·(‖x−x_w‖² + LPIPS(x, x_w))
  ```

### 2.5 理论保证：条件码片空间分析（Theorem 1）

- 在"码字无关扰动"假设下（攻击诱导的扰动 Δ 与秘密码本统计独立），匹配滤波统计量的偏移满足：
  - E[Δρ_i] = 0，Var[Δρ_i] ≤ B²/d²（B 为扰动能量上界）
  - 单比特翻转概率 ≤ exp(−α²d²/(2KB²))
- 攻击要达到常数比例 ρ₀ 的比特翻转，需要预算 B ≥ αd/√(2K·ln(1/ρ₀)) = Ω(αd/√K)；
- 在像素空间（L-Lipschitz 码片映射，L∞ 约束 ε）下等价于 ε = Ω(α√d/(L√K))。
- **含义**：密集扩展使得扰动需求随图像维度 d 的平方根增长；若比特只占据比例 φ 的坐标，所需预算将降低约 √φ 倍。

## 6. 主要结论与发现

1. **印记集中是普遍现象**：9 种现有方案的 per-bit footprint 均很小（0.005–0.182），SpreadMark 显著更高，验证了"现有方案将比特集中在局部"的假设。
2. **再生攻击下的突出表现**：SpreadMark 是唯一在再生攻击下保持高检测的方案（COCO：BA 0.78、DA 0.77；DIV2K：BA 0.73、DA 0.60），而所有基线 DA 接近为零。
3. **潜空间稀疏化下的完全鲁棒**：在两个数据集上 BA 和 DA 均保持 1.00，且随投影秩增大不衰减。
4. **标准失真下的表现**：JPEG 和加性噪声鲁棒性有竞争力（BA 0.89–1.00），但对模糊和裁剪缩放较弱（DA 0.05–0.31），原因在于固定空间码被低通滤波衰减和重采样失同步。
5. **对抗移除是最薄弱环节**：30 dB 下 DA=0，但 24 dB 时恢复 BA 0.86、DA 0.98，说明该场景由嵌入能量而非接收器决定。
6. **消融结论**：
   - 匹配滤波路径提供了稀疏化、再生和失真鲁棒性（卷积头在这些场景落后）；
   - 卷积头在对抗移除下反超匹配滤波（0.61 vs 0.35 BA）；
   - SA-AT 主要贡献于再生和 JPEG（DA 从 0.51→0.81，0.95→1.00），稀疏化鲁棒性完全来自密集嵌入；
   - 高斯码字与 Bernoulli 码字表现接近，学习 α 是便利而非必需。
7. **理论结果**：定理 1 验证了密集扩展对抗码字无关扰动的有效性，但其前提假设（独立性）不适用于自适应攻击。

## 7. 优点

1. **问题定义有据可依**：通过实际测量（per-bit footprint）提出假设，而非凭空提出设计理念，形成了"测量→假设→设计→验证"的完整研究链条。
2. **结合经典与现代**：将经典的扩频嵌入原则有机融入现代神经网络水印架构，匹配滤波可独立消融和分析（不同于隐式编码），设计具有可解释性。
3. **理论分析严谨且有边界**：定理 1 明确列出前提假设（A1–A3），并在"Scope"段落中坦率说明理论不覆盖的情形（自适应攻击、再生、压缩等），没有过度声称安全性。
4. **实验设计相对公平**：重新训练基线在匹配条件下比较，检查点基线在其原生条件下运行，并明确说明两组质量工作点差异；SA-AT 消融中说明质量差异方向有利于消融模型（28.7 vs 30.1 dB），使结论更可信。
5. **诚实的失败报告**：明确指出高分辨率再生是"真实的局限性"，对抗移除是"最弱列"，没有回避弱点。
6. **综合鲁棒性突出**：是唯一在再生和稀疏化同时保持高检测的方案，这一"组合鲁棒性"在深伪检测应用场景中至关重要。

## 8. 不足与局限

### 实验层面的局限

- **未报告种子方差**：每个配置仅一条训练运行，缺少多次运行的标准差，统计显著性存疑；
- **分辨率局限**：主实验仅在 128×128 下进行，256 分辨率下再生攻击 DA 接近零，作者承认该结果不能推广到全分辨率图像；
- **检查点组不匹配**：CIN、TrustMark 等使用原生分辨率（256）和负载（30–64比特），与 SpreadMark 的对比存在"质量工作点"差异，鲁棒性排序需谨慎解读；
- **无已知明文/选择明文攻击**：论文明确未测试已知消息、选择消息、合谋攻击、水印复制攻击等自适应威胁。

### 方法层面的局限

- **码本安全假设过强**：使用单一固定秘密码本，假设其永不被估计或泄露。密集扩展反而让每个水印图像暴露更多码字信息，可能降低码字估计难度；论文承认"密集传播是一把双刃剑"；
- **定理适用性有限**：Theorem 1 的码字无关扰动假设不适用于能观察到 x_w 的攻击（因 x_w 本身依赖码字），且只是期望预算陈述，非高概率保证；
- **空间失同步脆弱**：对高斯模糊（DA 0.05–0.12）和裁剪缩放（DA 0.24–0.31）表现弱，固定空间码缺乏重同步机制；
- **对抗鲁棒性依赖嵌入能量**：白盒攻击下除非提高嵌入强度（牺牲不可感知性），否则 DA 降为零；
- **不可感知性不极致**：PSNR 30.1 dB 显著低于 TrustMark（41.2 dB）、RivaGAN（40.1 dB）等，仅优于重训练基线的 24 dB 水平，在高保真场景可能受限。

### 应用层面的局限

- **后处理部署模型**：只适用于已有图像的嵌入，不适用于生成时水印（需要控制生成过程）场景；
