## 摘要
生成式AI系统日益产生来源难以验证的内容，这推动了用于识别模型生成输出的水印技术。现有的密码学水印方法提供了强大的不可检测性保证：在没有检测密钥的情况下，含水印输出与未含水印输出在计算上是不可区分的。然而，这些方法并未解决如何安全地委派检测能力这一关键部署挑战。如果拥有不受限制的检测密钥，恶意检测者可能超出预期范围使用该密钥，从而能够进行水印清除、范围滥用和用户画像分析。为了缓解这一安全问题，据我们所知，我们首次提出了面向生成式AI模型的基于属性的水印，提供细粒度、策略控制的水印检测。在我们的方法中，每个生成的输出都与属性相关联，每个检测密钥都受到关于潜在属性的策略约束。检测密钥只能用于检测其属性满足相应策略的含水印输出，而策略范围之外的含水印输出在计算上仍与未含水印输出不可区分。我们构建了这样一个基于属性的水印方案，并形式化了其安全属性，包括一致性、对有限破坏的自适应鲁棒性、不可检测性和可靠性，同时提供了在标准密码学假设下的安全性证明。我们的构造将受限伪随机函数、伪随机纠错码和随机性恢复过程与生成式AI模型集成在一起。最后，我们实现了原型并进行了实证评估，证明基于属性的水印既有效又实用。

## Abstract
Generative AI systems increasingly produce content whose provenance is difficult to verify, motivating watermarking techniques for identifying model-generated outputs. Existing cryptographic watermarking methods provide strong undetectability guarantees: without a detection key, watermarked outputs are computationally indistinguishable from unwatermarked ones. However, these approaches do not address the crucial deployment challenge of how to safely delegate detection capabilities. With an unrestricted detection key, a malicious detector may use the detection key beyond its intended scope, enabling watermark sanitization, scope abuse, and user profiling.   To mitigate this safety concern, we introduce, to the best of our knowledge, the first \emph{attribute-based watermarking} for generative AI models, providing fine-grained, policy-controlled watermark detection. In our approach, each generated output is associated with attributes, and each detection key is \emph{constrained by a policy} on potential attributes. A detection key can only be used to detect watermarked outputs whose attributes satisfy the corresponding policy, while watermarked outputs that fall outside the policy remain computationally indistinguishable from unwatermarked ones. We construct such an attribute-based watermarking scheme and formalize its security properties, including consistency, adaptive robustness to bounded corruptions, undetectability, and soundness, along with a security proof under standard cryptographic assumptions. Our construction integrates constrained pseudorandom functions, pseudorandom error-correcting codes, and randomness recovery procedures with generative AI models. Finally, we implement a prototype and an empirical evaluation, demonstrating that attribute-based watermarking is both effective and practical.

## 1. 论文的核心问题与整体含义（研究动机和背景）

生成式AI系统（如大语言模型、图像/音视频生成模型）产出的内容与人类创作越来越难以区分，这使得**内容溯源**（content provenance）成为关键的技术与政策挑战。水印技术通过在生成内容中嵌入可统计验证的信号，使得授权方能够判断某段内容是否由特定模型生成。

**现有方法的不足**：已有的密码学水印方案（如不可检测水印，undetectable watermarking）提供了很强的安全性保证——没有检测密钥的人无法将含水印输出与普通模型输出区分开。然而，这些方案均未解决一个关键的部署难题：**如何安全地委派检测能力**。如果检测密钥是无限的、不受约束的，那么获得密钥的恶意检测者就可能：

- **水印清除（Watermark sanitization）**：反复编辑输出并查询检测器，利用检测器作为"净化预言机"来移除水印；
- **范围滥用（Scope abuse）**：将在某一场合获得的检测能力用于其他场合，例如将企业合规检测密钥用于检测内部员工文档；
- **用户画像（User profiling）**：任意扫描用户公开内容中的水印，推断其依赖AI辅助的领域，从而实施定向钓鱼、操纵或声誉攻击。

现有水印方案只认证"内容是否含水印"，但不提供**密码学层面的访问控制**——即不约束谁能检测、检测什么内容、依据什么策略检测。论文以ICML 2026审稿政策违规检测为例说明非密码学溯源机制的脆弱性：隐藏指令一旦被公开就容易被规避。

**整体含义**：本文提出了第一个**基于属性的水印（attribute-based watermarking）**框架，实现了细粒度、策略控制的检测委派。每个生成输出关联属性（如主题、领域、课程标识、政策类别等），每个检测密钥受策略约束，只能检测属性满足该策略的输出；策略范围外的含水印输出在计算上与未加水印不可区分。

## 2. 论文提出的方法论

### 2.1 核心思想

论文的核心设计思路是：**用受限伪随机函数（Constrained Pseudorandom Function, CPRF）将水印随机性与输出属性绑定**，从而实现策略约束的检测委派。具体地：

- 主密钥（master secret key）允许模型提供者针对任意属性生成含水印输出；
- 委派的检测密钥对应一个策略（policy），仅允许在授权属性上求值相应的伪随机值；
- 策略未覆盖的属性上，检测密钥不泄露任何有用信息。

### 2.2 安全模型与定义

论文形式化定义了四个安全属性：

- **一致性（Consistency）**：当策略授权检测某属性时，委派检测与主检测结果一致（概率1−negl(κ)）；
- **自适应鲁棒性（Adaptive Robustness with Detection）**：即使对手持有策略f的检测密钥，也无法在δ-距离内移除属性不满足f的含水印输出中的水印；
- **不可检测性（Undetectability）**：持有未授权检测密钥的对手无法区分含水印输出与普通模型输出；
- **可靠性（Soundness）**：持有检测密钥的对手无法构造出属性不满足策略、却被主检测识别为含水印的输出。

### 2.3 构造方案（Construction 1）

设Model为生成模型，Classifier为属性分类器，RandRecover为随机性恢复算法，并采用以下密码原语：PRG（伪随机生成器）、CPRF（受限伪随机函数）、PRC（伪随机纠错码）。

方案由五个算法组成：

- **Setup(1^κ)**：运行CPRF的密钥生成算法，输出主密钥msk；
- **Issue(msk, f)**：运行CPRF.Constrain(msk, f)，为策略f输出受约束的检测密钥dk_f；
- **Generate(msk, π)**：
  1. 采样普通模型输出out' ← Model(π)；
  2. 通过分类器获得属性x ← Classifier(out')；
  3. 计算r ← CPRF.Eval(msk, x)，即从主密钥导出与该属性绑定的伪随机值；
  4. 以PRG(r)为种子生成PRC密钥s ← PRC.Gen(1^κ; PRG(r))；
  5. 生成PRC码字c ← PRC.Enc(s)；
  6. 用c作为生成模型的随机性，输出out ← Model(π; c)；
- **Detect(dk_f, out)**：
  1. 分类得到x ← Classifier(out)；
  2. 用受限密钥计算r ← CPRF.CEval(dk_f, x)（仅当f(x)=1时正确）；
  3. 恢复PRC密钥并执行解码：s ← PRC.Gen(1^κ; PRG(r))，c ← RandRecover(out)，d ← PRC.Dec(s, c)；
  4. 输出1当且仅当d=1；
- **MasterDetect(msk, out)**：与Detect类似，但用主密钥计算r ← CPRF.Eval(msk, x)。

**安全性证明**：论文在附录B中基于CPRF的正确性与安全性、PRG的伪随机性、PRC的伪随机性/可靠性/自适应鲁棒性，以及模型随机性恢复的鲁棒性，逐一证明了四个安全属性（Lemmas 15–18）。
