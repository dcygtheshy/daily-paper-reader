## 摘要
随着基于云的AI服务的扩展，多租户环境中的安全数据保护事务运行在私有受保护的认证平台上，这些平台由安全处理环境运行。为应对这种安全泄漏问题，我们提出了一种保护性解决方案，即结合基于密钥认证的受信任方之间的密钥分发，构建一个安全AI水印系统，以引导安全防护方式，利用算法实现主动和被动安全警报系统。所提出的系统可以在攻击发生前通过主动措施阻止，基于域运行限制访问。相反，所提出的系统被动方法用于捕获在联邦学习和远程学习算法中数据和模型交换过程中发生的、基于水印和生物特征的所有者设备特定知识产权泄漏。
