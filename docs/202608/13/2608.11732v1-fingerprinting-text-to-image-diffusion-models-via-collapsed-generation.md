## 摘要
专有的文本到图像扩散模型越来越多地以托管服务和可下载检查点的形式分发，这使得当模型泄露、复制或未经授权的微调发生争议时，其知识产权保护成为一个日益关键的问题。在这项工作中，我们提出了一种基于“塌缩生成”的非侵入式模型指纹识别框架，这是一种在多个随机种子下某些输入条件产生高度一致图像的现象。我们表明，塌缩生成是学习生成过程的一种内在的、依赖于模型的性质。这些易于塌缩的条件因此暴露了模型特定的行为特征，使得无需嵌入侵入性水印即可进行可靠的所有权验证。在源模型上准备条件后，该框架在两种访问设置下验证可疑模型：(1) 白盒流水线访问，其中优化的连续嵌入可以被注入生成过程；(2) 仅黑盒API访问，其中通过服务接口查询自然语言提示。在这两种情况下，所有权证据通过可疑模型是否在随机采样中重现源模型的塌缩行为来衡量。跨UNet和基于Transformer的扩散模型的广泛实验表明，塌缩生成指纹可以以低混淆度区分不同的源模型。这些指纹在微调衍生模型中以及在常见和自适应模型级或查询级混淆下仍然可验证，同时只需要适度的验证查询预算。这些结果共同确立了塌缩生成作为非侵入式扩散模型所有权验证的可靠内在证据来源。

## Abstract
Proprietary text-to-image diffusion models are increasingly distributed as hosted services and downloadable checkpoints, making their intellectual property (IP) protection an increasingly critical concern when model leakage, copying, or unauthorized fine-tuning is disputed. In this work, we present a non-invasive model fingerprinting framework based on \emph{collapsed generation}, a phenomenon where certain input conditions produce highly consistent images across multiple stochastic seeds. We show that collapsed generation is an intrinsic, model-dependent property of the learned generation process. These collapse-prone conditions therefore expose model-specific behavioral signatures, enabling reliable ownership verification without embedding invasive watermarks. After preparing conditions on the source model, the framework verifies a suspect model under two access settings: (1) white-box pipeline access, where optimized continuous embeddings can be injected into the generation process, and (2) black-box API-only access, where natural language prompts are queried through the service interface. In both cases, ownership evidence is measured by whether the suspect model reproduces the source model's collapse behavior across stochastic samplings. Extensive experiments across UNet- and transformer-based diffusion models show that collapsed generation fingerprints can distinguish different source models with low confusion. These fingerprints remain verifiable in fine-tuned derivatives and under common and adaptive model- or query-level obfuscations, while requiring only a modest verification query budget. Together, these results establish collapsed generation as a reliable intrinsic evidence source for non-invasive diffusion model ownership verification.

## 1. 核心问题与整体含义

- **研究动机**：文本到图像（T2I）扩散模型通常以托管 API 或公开检查点形式分发，容易被泄露、复制或未经授权微调，引发知识产权（IP）争议。现有保护手段分为侵入式水印（需要修改模型参数或训练过程）和非侵入式指纹（利用模型固有行为），但已有非侵入式方法存在局限：
  - 白盒方法（如 FingerInv、DiffIP）依赖内部表征、中间去噪状态或特殊采样流程，不适用于仅暴露最终图像的托管服务。
  - 黑盒方法（如 TVN）依赖优化后的对抗性提示后缀，语言异常且语义偏移明显，容易被服务端检测或过滤。
- **本文核心思想**：提出一种基于 **塌缩生成（Collapsed Generation）** 的非侵入式模型指纹识别框架。塌缩生成是指某些输入条件下，扩散模型在多个随机种子的采样中会收敛到高度一致的输出。该现象是模型自身学习过程（数据分布、优化动态、网络结构）的内在属性，因此可作为模型特异的“行为签名”。
- **整体含义**：该框架允许模型所有者在白盒流水线访问（注入连续嵌入）和黑盒仅 API 访问（自然语言提示）两种场景下统一进行所有权验证，无需修改模型、保持模型完整性与生成质量，为非侵入式扩散模型 IP 保护提供了新思路。

## 2. 方法论

### 2.1 核心定义

- 对给定条件嵌入 \(c\) 和 \(K\) 个独立初始噪声，定义跨种子一致性：
  \[
  \bar{s}_\theta(c,K)=\frac{2}{K(K-1)}\sum_{i<j} s(x_0^{(i)}(c), x_0^{(j)}(c))
  \]
  其中 \(s(\cdot,\cdot)\) 为感知相似度（本文使用 SSCD 分数）。若 \(\bar{s}_\theta \ge \tau_s\)，则称该条件触发塌缩生成。
- 塌缩行为具有模型特异性：同一提示在不同模型上诱发的塌缩强度差异明显（如图 2(b) 所示），因此可作为指纹信号。

### 2.2 指纹构建：白盒连续嵌入合成

- 在白盒设置下，验证者可控制推理流水线，因此将指纹条件表示为连续文本嵌入。
- 方法：从初始嵌入 \(c_i\) 出发，采样 \(K\) 个独立初始噪声，通过**截断优化（Truncated Optimization）**最小化早期去噪阶段的中间潜变量离散度：
  \[
  L_{\text{Collapse}}(c_i)=\frac{1}{K}\sum_{k=1}^{K}\left\|x_{T-t_{\text{trunc}}}^{(k)}(c_i)-\bar{x}_{T-t_{\text{trunc}}}(c_i)\right\|_2^2
  \]
  其中 \(\bar{x}\) 为 \(K\) 条轨迹的平均。只对前 \(t_{\text{trunc}}\) 步求梯度，跳过完整去噪、VAE 解码和图像级相似度计算，大幅降低计算和显存开销。
- 重复该过程 \(M\) 次得到指纹集 \(C_f=\{c^*_i\}_{i=1}^M\)。

### 2.3 指纹构建：黑盒自然提示挖掘

- 在黑盒仅 API 访问下，指纹条件必须为文本提示。论文发现，训练损失极低的样本中塌缩样本显著富集（图 6）。
- 构造流程：
  1. 训练时记录每个样本的逐样本去噪损失；
  2. 用低损失阈值筛选出候选池 \(P_{\text{cand}}\)；
  3. 对候选池中的每个提示生成 \(K\) 张图像并计算一致性，选择一致性最高的 \(M\) 个提示组成 \(P_f\)。
- 该策略避免了在大规模候选空间上进行穷举生成式搜索，使自然塌缩提示可高效发现。

### 2.4 指纹验证

- 统一验证原理：将指纹条件应用到嫌疑模型，生成 \(K\) 个独立输出，计算平均跨种子一致性；对 \(M\) 个指纹条件聚合得到 \(\bar{s}_f\)。
- 统计判定：在源模型上，用 \(N=50\) 个正常提示（GPT-4 生成）建立正常生成一致性参考分布，计算均值 \(\mu_0\) 和标准差 \(\sigma_0\)，然后进行右尾预测 t 检验：
  \[
  t_f=\frac{\bar{s}_f-\mu_0}{\sigma_0\sqrt{1+1/N}},\quad p_{\text{val}}=1-F_{t_{N-1}}(t_f)
  \]
- 若 \(p_{\text{val}}<\tau_f\)（默认 \(10^{-4}\)），则判定嫌疑模型源自源模型。
- 验证协议支持跨会话、多客户端收集样本，默认配置 \(M=4, K=4\) 共 16 次查询，以保证隐蔽性。

## 3. 实验设计

### 3.1 基准与场景

论文没有统一的外部 benchmark，而是构建了一套自有的评估协议，覆盖以下场景：

- **受控初步实验**：在 CIFAR-10 上训练 4 个独立的条件 DDPM（相同架构、数据、优化器，不同随机种子），并选取 500 张图片 10× 过采样以增强塌缩效应，验证模型的唯一性。
- **白盒流水线访问**：评估 SD 1.4、DeciDiffusion v1.0、PixArt-α、SD 3，涵盖 UNet、DiT、flow-matching 等架构。
- **黑盒 API-only 访问**：评估 SD 1.4、SD 2.1，使用 Webster 提供的公开 500 提示集合作为候选池。
- **微调衍生模型**：SD 1.5（全量微调）、Deliberate v4、Realistic Vision v2.0（均为 SD 1.4 的社区微调衍生）。
- **自适应攻击**：GPT 重写、随机令牌添加（RTA）、嵌入优化（EO）、锐度感知初始化（SAIL）等四种查询/模型级混淆。

### 3.2 对比方法

- 白盒：对比 **FingerInv**（通过 DDPM 逆映射优化隐噪，用 QR 码恢复程度判定所有权）。
- 黑盒：对比 **TVN**（通过不可迁移对抗提示后缀产生目标特定语义偏差）。
- 评价指标：
  - 本文：SSCD 跨种子一致性 → \(p_{\text{val}}\)；
  - TVN：CLIP 分数（越低越好）；
  - FingerInv：QR 码 L2 距离（越低越好）；
  - 隐蔽性：Mistral-7B 计算困惑度（越低越自然）。

### 3.3 消融实验

- 指纹数量 \(M \in \{2,4,8\}\) 和生成数量 \(K \in \{2,4,8\}\) 对 \(p_{\text{val}}\) 的影响；
- 白盒优化中不同初始化策略（随机、低多样性提示、已有塌缩提示）对收敛效率的影响；
- 将白盒优化嵌入离散化为文本提示（后验投影、PEZ、GCG）的可行性，结果显示均失败。
