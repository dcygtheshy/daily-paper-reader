## 摘要
诸如 Tree-Ring 之类的语义水印方案会在扩散模型的初始噪声潜变量中隐藏一个可检测的模式。近期工作表明，这些水印不仅可被移除，还可被伪造：即使攻击者从未见过水印密钥，仍能生成真实检测器会接受的图像。我们使用作者发布的代码，在免费层双 T4 GPU（每设备可用内存 14.6 GB）上，复现了 Müller 等人针对 Stable Diffusion XL 上 Tree-Ring 的 Reprompt 伪造攻击；每 GPU 内存显著低于原研究所用的 A40 硬件。该攻击可复现。在三个实验分支共六次试验中，我们对真实图像的检测结果为 6/6，对干净图像的检测结果为 0/6，对伪造图像的检测结果为 5/6，每次攻击耗时 325–332 秒。在受限条件下运行该攻击还得到三项进一步结果。发布的检测器计算一个非中心 χ² 统计量并只返回其 CDF，因此我们恢复了被丢弃的统计量；我们的恢复与发布的检测器完全一致，并且基于该统计量构建的两个自然得分在相同的十八个观测上，将伪造分支与干净零假设区分开，AUC 分别为 0.861 和 0.972。以半精度运行 SDXL 需要修补流水线中直接调用自编码器的地方，受控探测确认修补后的路径不会改变检测器统计量。最后，我们报告一项我们通过阅读检测器源代码所作的预测，而我们的测量结果随后与其相矛盾。Jupyter notebook、固定版本的 fork 以及所有测量产物均随论文发布。

## Abstract
Semantic watermarking schemes such as Tree-Ring hide a detectable pattern in the initial noise latent of a diffusion model. Recent work shows these watermarks are not only removable but forgeable: an attacker who never sees the watermarking key can still produce images the genuine detector accepts. We reproduce the Reprompt forgery attack of Müller et al. against Tree-Ring on Stable Diffusion XL, using the authors' released code, on free-tier dual T4 GPUs with 14.6 GB of usable memory per device, substantially less per-GPU memory than the A40 hardware used in the original study. The attack reproduces. Over six trials of three arms we detect genuine images 6/6, clean images 0/6, and forged images 5/6, at 325-332 s per attack. Three further results came out of running it under constraint. The released detector computes a non-central $χ^2$ statistic and hands back only its CDF, so we recovered the discarded statistic; our recovery matches the released detector exactly, and two natural scores built from it separate the forged arm from the clean null at AUC 0.861 and 0.972 on the same eighteen observations. Running SDXL in half precision requires patching the pipeline's direct autoencoder calls, and a controlled probe confirms the patched path leaves the detector statistic unchanged. Finally, we report a prediction we made from reading the detector source that our measurements then contradicted. The notebook, the pinned fork and every measurement artifact are released with the paper.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：文本到图像扩散模型已足够逼真，"图像是否由机器生成"成为现实问题；水印是主流应对手段之一。语义水印（如 Tree-Ring）不做事后像素扰动，而是把密钥派生的模式（傅里叶域的同心环）写入初始高斯噪声潜变量 $z_T$，使标记成为生成轨迹的属性，因而能抵抗压缩、裁剪、模糊等像素域攻击。
- **核心问题**：鲁棒性不等于可溯源性。如果攻击者能**制造**出被真检测器接受的水印，溯源机制就失效。Müller 等人（CVPR 2025）已证明 Tree-Ring 与 Gaussian Shading 可被黑盒伪造：攻击者只需一张水印参考图，在从未见过密钥的代理模型中做 DDIM 反演，再用恢复的潜变量生成任意新图，即可通过真检测器。
- **本文定位**：不是质疑原结论，而是在**自己可控、算力受限的硬件上独立复现**该攻击，建立可验证基线，并在过程中对检测器做插桩。作者引用复现性研究（Olszewski 等，CCS 2023）：约 750 篇 ML 安全论文中 60% 未发布代码，56% 已发布工件无法运行——独立复现本身即为正当研究活动。
- **整体含义**：伪造造成**假阳性**（非目标模型产出的图像被归因于该模型），而溯源声明的可信度恰恰取决于这一错误率；鲁棒性评估与伪造抗性测量的是**正交属性**。本文说明黑盒伪造在**免费消费级硬件上不到 6 分钟**即可完成。

## 2. 方法论：核心思想、技术细节与流程

### 2.1 攻击复现（Reprompt）
- **攻击概念**（Müller 等原创）：环模式能穿越**异模型**的 DDIM 反演。攻击者持有水印参考图 $x^{(w)}$，在代理模型 $u_A$ 中反演得 $\hat z_T^{(w)}$，再在任意提示词下重新生成，输出内容与原图无关但真检测器仍接受。无需密钥、无需梯度、无需目标模型特权访问。
- **一次测量试验（Algorithm 1）**：
  1. $z_T^{(w)} \leftarrow \text{WATERMARK}(k)$（密钥派生潜变量）
  2. $x^{(g)} \leftarrow G(u_T, q_T, z_T^{(w)})$ —— genuine 臂
  3. $x^{(c)} \leftarrow G(u_T, q_T, \varepsilon)$，$\varepsilon \sim \mathcal N(0,I)$ —— clean 零假设臂（**本文新增**）
  4. $\hat z^{(w)} \leftarrow I(u_A, x^{(g)})$ —— 在攻击者模型中反演
  5. $x^{(f)} \leftarrow G(u_A, q_A, \hat z^{(w)})$ —— forged 臂（提示词 $q_A$ 与 $q_T$ 无关）
  6. 对三个 $x$ 各自在目标模型反演并送入检测器，记录 $(x, \lambda, df, \sigma, p)$
- **边界声明**：攻击概念、DDIM 反演、Tree-Ring 检测器、扩散模型与提示词集合均属 Müller 等；**循环组装、clean 零假设臂、被丢弃统计量的恢复及其验证**为本文贡献。

### 2.2 检测器公式与统计量恢复（插桩核心）
- 释放版检测器计算（$f$ 为恢复的掩码系数，$t$ 为密钥模式，$\sigma$ 为 $f$ 的标准差）：

$$x=\sum_i\left(\frac{f_i-t_i}{\sigma}\right)^2,\qquad \lambda=\sum_i\frac{t_i^2}{\sigma^2}$$

  并返回 $p=F_{\chi'^2}(x;\,df,\lambda)$，$p<\tau$ 判为检出（SDXL 在 1% FPR 下 $\tau=0.0261008646426459$）。
- **问题**：$x,\lambda,df,\sigma$ 全部被计算后丢弃，只返回 CDF 值。CDF 是尾部概率，强证据被压缩在接近 0 的窄带内；accuracy 访问器返回 $1-p$ 进一步饱和。差异化的 $p$ 不对应可比较的"频谱匹配程度"差异。
- **做法**：用同一算术重实现 Equation 1（Listing 2），保留全部中间量；在全部 18 个观测上把恢复的 $x$ 重新推回同一 CDF，与释放版检测器比对，断言绝对差 $<10^{-12}$——实测**最大绝对差恰为 0**，排除重实现误差。
- **两个候选分数**（同一统计量的不同变换）：
  - $-\!x$：原始差异，越小越匹配；
  - $\lambda - x$：用非中心参数校正，而 $\lambda$ 通过 $\sigma$ 依赖图像，故两分数**非单调相关**（$\sigma$ 跨 31.75–42.59，$\lambda$ 跨 856.6–1541.4）。
  - 作者强调：**分数必须在看到分离效果之前预先固定**，事后择优选报即是对测试集的选择。

### 2.3 半精度兼容补丁
- 释放代码在模块级硬设 `DTYPE = torch.float32`，无半精度路径。
- 故障定位：SDXL 自编码器配置含 `force_upcast=True`，但 `diffusers` 流水线仅在自身 `__call__` 内遵守该标志；仓库在 `vae_encode` / `latents_to_imgs` 中**直接调用自编码器**，绕过了该处理，fp16 下溢出，检测返回 NaN 潜变量（而图像质量指标正常）。
- 修复：fork 中新增 `_vae_upcast` 辅助函数，保存自编码器 dtype，在 fp16 且 `force_upcast` 为真时提升至 fp32，调用后恢复，包裹每一次直接编码/解码。

### 2.4 工程可复现性方法（作为"发现"报告）
- 所有改动放在**固定 commit 的 fork** 中而非运行时 monkey-patch（子进程不可见父进程补丁；脏工作树能通过 hash 校验却运行非记录代码）；notebook 执行 `git reset --hard` + `git clean -fd`，重读 HEAD 并断言 `git status --porcelain` 为空。
- 每次运行开始时序列化会话元数据：fork 与上游 commit hash、模型标识、dtype、设备分配、库版本、依赖锁 SHA-256。

## 5. 实验数量与充分性

- **实验规模**：
  - 主实验：**6 次试验 × 3 臂 = 18 个观测**，生成种子 123–128，水印密钥固定（`w_seed = 999999`）。
  - 完整流水线在**相隔 11 天的两个独立会话**中各跑一次，从干净环境重建；所有统计量复现到末位有效数字，仅墙钟时间波动 2.2%。
  - 1 次半精度受控探针（将反演拆为 `imgs_to_latents` 与 `invert_z0` 两阶段，在两种 dtype 下对同一固定生成图运行）。
  - 1 组事后统计检验电池：bootstrap 置信区间、Mann-Whitney 检验、Cohen's d 效应量。
- **充分性与客观性评价（作者自评，本文亦认可）**：
  - 规模足以**确立"攻击可复现、统计量可恢复"**，不足以做任何分布性论断。
  - **单密钥**是最大缺陷：18 个观测共享同一密钥，是**密钥内变异**而非密钥空间上的独立抽样；Ci 等已证明 Tree-Ring 在多密钥场景行为不同，故该限制比在鲁棒性研究中更严重。
  - **配对设计 vs 非配对检验**：试验内配对（第 $i$ 次伪造图派生自第 $i$ 次真实图，clean 图共享提示词），故非配对检验并非自然选择。
  - **分辨率极限**：$n=6$/臂时，双侧 Mann-Whitney 最小可能 $p = 2/\binom{12}{6} = 0.0022$，精确配对 Wilcoxon 最小可能 $p = 2/2^6 = 0.0312$；落在下限只说明完全分离，无更细信息。
  - **多重比较未校正**：三个比较在 Bonferroni $\alpha = 0.05/3$ 下，配对检验在两个分数上都不存活（已被 0.0312 下限注定），非配对检验在 $\lambda-x$ 上存活、在 $-\!x$ 上不存活。作者明确：**结论依赖分数与检验的选择，在 18 个观测
