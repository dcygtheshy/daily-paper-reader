## 摘要
不可见水印通常针对预定义的扰动进行评估，如压缩、模糊、噪声、裁剪和去噪。公共基础图像模型暴露了一种独特的威胁：攻击者只需提交一个带有单一重建提示的含水印图像，即可获得视觉上忠实的输出，而该输出中的不可见水印无法再被可靠解码。我们将这种失败模式正式化为水印清洗，并使用联合载荷-保真度曲线进行评估，该曲线结合了比特错误率与视觉和语义保持。在六个OpenAI和Google图像编辑模型、三种代表性水印方案以及1,800个重建输出中，我们识别出两种互补的清洗机制：OpenAI模型在评估的方案中产生最强的载荷破坏，而Nano Banana 2显示在高保真重建下DwtDct仍然易受攻击。提示消融实验表明，实现载荷破坏并不需要任何特定的移除导向指令，这表明该效应主要是由重建路径而非明确攻击措辞引起的。与传统攻击的比较进一步表明，基于提示的重建构成了一种独特的操作攻击接口。这些发现促使将基础模型重建视为不可见水印评估中缺失的鲁棒性条件。

## Abstract
Invisible watermarks are typically evaluated against predefined perturbations such as compression, blur, noise, cropping, and denoising. Public foundation image models expose a distinct threat: an attacker can submit a watermarked image with a single reconstruction prompt and obtain a visually faithful output from which the invisible watermark can no longer be decoded reliably. We formalize this failure mode as watermark laundering and evaluate it using a joint payload-fidelity profile that combines bit error rate (BER) with visual and semantic preservation. Across six OpenAI and Google image editing models, three representative watermarking schemes, and 1,800 reconstructed outputs, we identify two complementary laundering regimes: OpenAI models produce the strongest payload disruption across the evaluated schemes, whereas Nano Banana 2 shows that DwtDct remains vulnerable under high-fidelity reconstruction. Prompt ablations show that no single removal-oriented instruction is necessary for payload disruption, indicating that the effect is primarily induced by the reconstruction pathway rather than by explicit attack wording. Comparisons with conventional attacks further show that prompt-conditioned reconstruction constitutes a distinct operational attack interface. These findings motivate foundation-model reconstruction as a missing robustness condition in invisible watermark evaluation.

# 论文详细总结

## 1. 论文的核心问题与整体含义

- **研究动机**：传统不可见水印的鲁棒性评估只覆盖固定的信号处理扰动（如压缩、模糊、噪声、裁剪、去噪）或专用去除模型，而很少考虑公共基础图像模型可能被攻击者直接用来清洗水印。公共图像编辑模型只需一句自然语言重建提示，就能输出视觉和语义基本一致的图像，同时使受害者水印无法被解码。
- **核心问题**：将这种通过基础模型重建导致水印失效的失败模式形式化为 **“水印清洗”**（Watermark Laundering）。水印清洗需同时满足两个条件：载荷被破坏（BER 向随机值 0.5 靠近）且输出图像仍保持可用、与源图像在视觉/语义上相关。若输出已经被严重破坏，则只是普通删除而非清洗。
- **整体含义**：作者认为基础模型的重建路径是一个独立且缺失的操作攻击面，应当被补充进不可见水印鲁棒性评测和模型安全设计中。该工作不等同于绕过具体平台策略，也不等同于法律上的版权转移。

## 2. 论文提出的方法论

- **威胁模型假设**：
  - 攻击者为黑盒，只能通过公共 API 向基础图像编辑模型提交含水印图像 + 一条自然语言提示；
  - 攻击者不知道受害者水印算法、嵌入密钥、模型参数、梯度，也没有解码器反馈；
  - 编辑器返回的是重新渲染的像素，而不是调优过的局部加性扰动。
- **形式化定义**：
  - 定义 `Watermark Laundering`：变换 `x_V -> y`，当 `Decode_WV(y)` 对载荷 `b` 的估计不可靠，且 `y` 在视觉和语义上仍然忠实于 `x_V`。
  - 联合评估曲线：使用五元组 `(BER, M_ref, M_clean, M_sem, M_nr)`，分别表示原始比特错误率、对水印输入的保真度、对干净图像的保真度、语义保持度、无参考图像质量。
  - 提出随机解码边界：BER 接近 0.5 表示载荷恢复趋向随机；超过 0.5 不视为更强的攻击。
  - 还引入 `R_BER(D)=1-2|BER-0.5|`，以及概念性的阈值判据 `R_BER >= tau_RR 且 Sim_D >= tau_sim`，但实际实验不设阈值，而是用连续联合曲线避免掩盖权衡。
- **信息论解释**：
  - 假设 `b -> x_V -> Z -> y` 的马尔可夫链，其中 `Z` 是编辑器用于重建的内部表示。
  - 关键条件：语义充分性（`Z` 保留可见场景 `C` 的信息）、取证不足性（给定 `C` 后 `Z` 对载荷 `b` 的互信息很小）。
  - **命题1（重建瓶颈）**：由数据处理不等式，`I(b; y | p) ≤ I(b; Z)`，即表示若已经几乎不含载荷信息，下游解码不可能可靠恢复。
  - **命题2（最优恢复的误差界）**：基于 Fano 不等式，若每个载荷比特与输出之间互信息很小，任何估计器的最小错误概率都接近 0.5。
  - 该瓶颈理论还预言：提示词的具体措辞对 BER 影响不大（因为载荷已经在重建表示中丢失）；但提示会影响保真度。
- **高频率残差分析（HFR）**：定义 `HFR = ||P_H(y)-P_H(x_V)||_2 / (||P_H(x_V)||_2 + eta)`，用于度量重建前后高频 DCT 系数的变化，解释部分解码器错误。
- **实验提示设计**：使用结构化提示 `P_struct`，包含画布、几何、亮度、色彩、外观、隐藏信号处理等约束模块；并做消融版本测试。

## 3. 实验设计

- **数据集**：使用 MS-COCO 中的 100 张图像，按分层策略选取：40 张纹理丰富、30 张有大的平坦区域、30 张包含文字。所有干净参考图先缩放至 1024×1024，再嵌入水印。
- **水印方案**：DwtDct、DwtDctSvd、RivaGAN。
- **基础图像模型**：
  - OpenAI 系列：GPT Image 1、GPT Image 1.5、GPT Image 2；
  - Google 系列：Nano Banana、Nano Banana Pro、Nano Banana 2。
- **主实验结构**：3 种水印 × 6 个模型 = 18 个组合，每个组合 100 张图，共 **1800 个主要 API 调用/输出**。
- **基准与对比**：
  - 传统攻击：Gaussian blur、Gaussian noise、contrast scaling、30° rotation、50% cropping、BM3D denoising；
  - 提示消融（仅在 DwtDct 上，针对 Nano Banana 2 和 GPT Image 2）：移除可见内容保持约束、移除亮度/色彩约束、移除外观/几何约束、移除显式隐藏信息语言、保留约束、最小提示；
  - 对比模型版本（GPT 1/1.5/2 之间，Nano Banana 各版本之间）；
  - 对输出做 C2PA/Content Credentials 标记审计。
- **评价指标**：
  - 载荷破坏：BER（越接近 0.5 表示相对随机恢复的破坏越强）；
  - 参考保真度：PSNR、SSIM、LPIPS、CLIP-Sim（对水印输入和干净输入分别报告）；
  - 无参考质量：NIQE、BRISQUE、CLIP-IQA；
  - 语义/高频：HFR 与 BER 的相关性分析。
- **失败处理**：API 调用偶发故障重试一次，持续失败则从同层替换下一张未用图像，避免嵌入失败被计入清洗。

## 6. 论文的主要结论与发现

- **单提示足可清洗水印**：一条普通的重建提示送入公共黑盒编辑器，足以让 3 种不可见水印方案的载荷 BER 明显向 0.5 靠近，同时输出保持视觉/语义可用。
- **两种互补清洗机制**：
  - OpenAI 模型普遍给出更激进的清洗效果，GPT Image 1 的平均 BER 最接近随机（0.4808）；GPT Image 2 在提高保真度的同时仍保留较高 BER 破坏。
  - Google 的 Nano Banana 2 保真度最高（平均 PSNR 30.27、SSIM 0.879），但 DwtDct 仍在该高保真条件下受到显著载荷破坏（BER 0.4110）。
- **提示措辞不重要**：显式“删除隐藏信息”词语并非必需；最小化/普通重建提示也能达到相近 BER。证明效果主要来自重建路径本身，而非特定攻击词语。因此依靠词法过滤难以防御该类行为。
- **算法间存在差异**：DwtDct 在多数模型上都保持 BER≈0.41；DwtDctSvd 和 RivaGAN 更容易在新版模型中恢复（BER 降低），说明不同水印方案的载荷放置、冗余和译码器不变性会影响被清洗的难易度。
- **版本趋势**：同厂商较新模型往往保真度更高、载荷保留能力也随之提高（即未简单加大破坏强度）；但也有例外（DwtDct 在 Google 系中仍保持稳定破坏）。
- **HFR 只是部分解释**：整体上 HFR 与 BER 正相关（Pearson r=0.316, Spearman 0.361），但在单个模型内相关性弱，说明高频变化不足以解释全部解码器错误。
- **安全启示**：水印鲁棒性与取证/来源安全不是同一件事；平台侧即使添加 C2PA 标记，也不能替代对受害方水印的恢复能力；防御方应把基础模型重建接口纳入评估，并考察输出是否丢失了原载荷信号。

## 7. 优点

- **问题定义新颖且准确**：提出“水印清洗”概念，巧妙借鉴“信息清洗”类比，将用户提示下的重建从普通加噪扰动中独立出来，补足了一个评估盲区。
- **攻击难度合理**：攻击者只需一条自然语言提示、单次黑盒 API 调用，无解码器反馈、无梯度、无本地训练，威胁模型务实且容易复现。
- **评估框架全面**：没有简单用“攻击成功率”或“BER”单指标下结论，而是联合 BER + 参考保真度 + 无参考质量，避免把破坏性摧毁误判为水印清洗。
- **理论给出可验证预期**：信息论瓶颈解释了“提示措辞不重要”和“BER 与保真度并行升高”等发现，并通过消融实验验证。

- **诚实区分测量对象**：作者明确“BER 上升”不等于“超过 0.5”；无参考质量高不等于贴近源图；C2PA 标记不等于来源替代，避免过度解读实验结果。

## 8. 不足与局限

- **方案/模型覆盖有限**：只有 DwtDct、DwtDctSvd、RivaGAN 三种较传统的水印，未覆盖 Stable Signature、Tree-Ring、Gaussian Shading 等生成式模型内嵌水印。

- **时效性风险**：模型版本与接口快速迭代，指标数值是 2026 年的时间快照，随着模型更新可能很快过时。
