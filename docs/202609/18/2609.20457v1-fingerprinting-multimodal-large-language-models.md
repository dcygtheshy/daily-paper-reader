## 摘要
尽管多模态大语言模型（MLLMs）支持广泛的图文推理任务，近期事件表明它们容易受到非法部署和未经授权蒸馏的侵害。现有的模型溯源方案通常会受到 MLLMs 中共享语言主干的干扰，并且难以检测蒸馏违规行为。为弥补这一空白并保护模型所有权，我们开展了首个关于多模态模型指纹识别的研究。受近期发现的启发——自注意力充当低通滤波器，且其低频分量具有信息量——我们提出了用于白盒溯源的 AttnPrint。具体而言，我们提取跨模态注意力分布，并分离其低频分量作为模型指纹。为便于黑盒审计，我们进一步提出 DistillTrace，它通过对 MLLM 输出进行假设检验来识别潜在的模型侵权。我们在 19 种多模态架构的 154 个模型实例上进行了大量实验。值得注意的是，AttnPrint 在保持对五种下游修改技术鲁棒的同时，实现了较强的衍生模型检测性能。DistillTrace 也在三种参数无关技术下提供了蒸馏关系的证据。

## Abstract
While multimodal large language models (MLLMs) enable a wide range of image-text reasoning tasks, recent incidents indicate that they are vulnerable to illicit deployment and unauthorized distillation. Existing solutions for model provenance are typically confounded by shared language backbones in MLLMs and struggle to detect violations of distillation. To bridge this gap and safeguard model ownership, we present the first study on multimodal model fingerprinting. Inspired by recent findings that self-attention acts as a low-pass filter and that its low-frequency components are informative, we develop AttnPrint for white-box provenance. Specifically, we extract cross-modal attention distributions and isolate their low-frequency components to serve as model fingerprints. To facilitate black-box auditing, we further introduce DistillTrace, which employs hypothesis testing of MLLM outputs to identify potential model infringement. We conduct extensive experiments on 154 model instances across 19 multimodal architectures. Notably, AttnPrint achieves strong derivative-model detection performance while remaining robust to five downstream modification techniques. DistillTrace also provides evidence of distillation relationships under three parameter-independent techniques.

## 1. 核心问题与整体含义

- **研究背景**：多模态大语言模型（MLLMs）在图文推理任务上表现优异，但面临严重的知识产权风险，包括非法部署与未经授权的蒸馏。文中引用真实事件：Anthropic 公开指控第三方模型通过商业 API 从 Claude 蒸馏；Llama-3-V 与 MiniCPM-V 之间也曾出现未授权衍生的争议。
- **攻击形式**：攻击者通过低成本操作（如微调、剪枝、量化、模型合并）构建"表面修改"的衍生模型，冒充独立开发成果；或通过查询教师模型输出训练学生模型，继承其能力。
- **核心问题**：现有面向 LLM 的指纹识别方法直接迁移到 MLLM 时失效，原因有二：
  - 这些方法以文本为中心，忽略跨模态对齐信息，当两个 MLLM 共享相同语言主干（如 Qwen2-VL-7B 与 LLaVA-OneVision-Qwen2-7B 共用 Qwen2）时会被错误地判定为同一模型；
  - 现有方法主要面向"从已知基座模型直接衍生"的检测，无法可靠捕获从特定教师模型继承的行为关系，因此对蒸馏检测基本无效。
- **整体含义**：本文首次系统研究 MLLM 指纹识别，为 MLLM 的来源认证与版权保护提供白盒与黑盒两类工具，并揭示跨模态注意力低频分量在溯源中的价值。

## 2. 方法论

### 2.1 威胁模型与任务定义

- 给定受害模型 $M_v$ 与可疑模型 $M_s$，设计决策函数 $f(M_v, M_s) \to \{0,1\}$，$1$ 表示存在未经授权的修改或蒸馏衍生关系。
- 考虑两种审计设置：
  - **白盒**：审计者可访问可疑模型的完整参数、网络架构与中间表示；
  - **黑盒**：仅能通过 API 在有限查询预算下观察生成文本、输出概率或 logits，必要时可对参考模型获得同等访问权限。
- 对蒸馏检测，额外假设模型所有者可构造与目标任务相关的查询样本（合理，因为蒸馏主要传递目标任务分布上的教师行为特征）。

### 2.2 AttnPrint（白盒指纹）

- **核心思想**：不同 MLLM 因架构、训练数据与优化策略差异，在处理相同多模态输入时形成不同的注意力分配模式；跨模态注意力（文本-视觉、视觉-文本）比文本-文本注意力更能反映模型特有的身份信息。t-SNE 可视化显示：有衍生关系的模型形成紧密局部簇，独立训练的模型分布于不同区域。
- **关键技术流程**：
  1. **提取跨模态注意力**：聚焦第 $l$ 层第 $h$ 个头的文本到视觉注意力子矩阵 $A^{t2v}_{l,h} \in \mathbb{R}^{T_l \times V_l}$（视觉到文本注意力因自回归掩码信息量较低）。
  2. **频域变换**：对每个文本 token 的注意力向量做离散傅里叶变换（DFT），得到频谱 $X^{t2v}_{l,h}[i,k]$。
  3. **低通滤波去噪**：仅保留低频分量（保留比 $\rho=0.2$），理想低通滤波器 $G(k)$ 保留 $\min(k, V_l-k) < \rho V_l/2$ 的分量，抑制微调、量化、模型合并引入的高频噪声。
  4. **逆变换回时域**：通过 IDFT 得到去噪后的注意力向量 $\hat{A}^{t2v}_{l,h}[i,n]$；依据 Parseval 定理，信号总能量在时频域保持不变，且经验上能量主要集中于低频段。
  5. **构造层级指纹**：对第 $i$ 个文本 token，计算低频注意力向量能量 $E_{l,h}[i]$；仅在头维度平均（保留 token 位置特异性），得到层级指纹 $S^l \in \mathbb{R}^{T_l}$。
  6. **固定维度表示**：对 token 维度做均值池化，得 $e^l(M) \in \mathbb{R}$；模型指纹为 $F(M) = [e^1(M), \dots, e^L(M)]^\top \in \mathbb{R}^L$。
  7. **层对齐**：因模型深度可能不同（架构差异或层剪枝），用匈牙利算法按池化能量统计做一对一层匹配，最小化匹配代价 $C_{i,j} = |e_i(M) - e_j(M')|$。
  8. **相似度度量**：对齐后使用 Pearson 相关系数 $r(M, M')$ 衡量两个指纹的一致性，越高越可能为衍生关系。

### 2.3 DistillTrace（黑盒蒸馏检测）

- **核心思想**：知识蒸馏以 KL 散度衡量学生与教师软分布的差异，因此若学生从教师蒸馏，其生成行为应更贴合教师的输出偏好，教师会对学生生成的输出赋予更高置信度。
- **关键技术流程**：
  1. **对数几率置信度**：商业 API 通常不暴露原始 logits，改用返回的对数概率 $p_t$ 计算对数几率 $\text{Logit}(p_t) = \log\frac{p_t}{1-p_t}$，并对整条序列取平均 $\bar{L}(M, y)$，避免长序列因概率累积被不公平地压低。
  2. **参考模型校准**：引入 $b$ 个独立参考模型，计算教师对参考模型输出的平均 logit 作为基线 $\bar{L}^{(i)}_{\text{refs}}$，用于近似独立模型输出分布并校准样本难度（避免"样本本身简单"导致的假阳性）。
  3. **配对差值**：对第 $i$ 个查询定义 $\Delta_i = \bar{L}(M_T, y_S^{(i)}) - \bar{L}^{(i)}_{\text{refs}}$，若存在蒸馏关系，差值分布应呈现正的位置漂移。
  4. **假设检验**：采用单侧 Wilcoxon 符号秩检验，$H_0: \theta_\Delta \le 0$ 对 $H_1: \theta_\Delta > 0$；去除零差值后对绝对值排序，计算正差值秩和 $W^+$，得到 $p$ 值。$p$ 值越小，蒸馏关系证据越强。
