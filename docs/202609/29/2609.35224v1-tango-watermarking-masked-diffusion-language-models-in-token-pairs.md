## 摘要
掩码扩散语言模型并行地、且不按固定顺序填充掩码位置。大多数实用文本水印假定从左到右生成。它们将每个词元与其之前的词元关联，而在扩散模型中，这些词元可能仍处于掩码状态。固定的绿名单不需要这种上下文，但它在每个位置都偏向相同的词元，因此这些词元在水印文本中出现得更频繁。攻击者通过比较水印文本与未加水印文本中的词元频率，就能恢复该名单，并伪造出提供商自己的检测器也能接受的文本。我们提出 TANGO，一种用于掩码扩散语言模型的水印，它将每个新词元与附近一个已经去掩码的词元关联。一个密钥将词表划分为颜色类别，TANGO 使新词元偏向由该密钥和附近词元的颜色共同决定的颜色。因此，水印被嵌入到词元对中。由于偏好的颜色随位置变化，词元频率比在固定绿名单下更接近未加水印文本的频率。检测仅需文本和密钥，且不假定任何去掩码顺序。在两个掩码扩散模型上，TANGO 能检测出几乎所有未经编辑的水印文本和大多数经过编辑的文本，而伪造固定绿名单的频率攻击对其无效。

## Abstract
Masked-diffusion language models fill in masked positions in parallel and in no fixed order. Most practical text watermarks assume left-to-right generation. They key each token to the tokens before it, and in a diffusion model those tokens may still be masked. A fixed green list needs no such context, but it favors the same tokens at every position, so these tokens appear more often in watermarked text. An attacker who compares token frequencies in watermarked and unwatermarked text can recover the list and forge text that the provider's own detector accepts. We present TANGO, a watermark for masked-diffusion language models that keys each new token to a nearby token that is already unmasked. A secret key splits the vocabulary into color classes, and TANGO biases the new token toward a color determined by the key and the nearby token's color. The watermark is therefore embedded in pairs of tokens. Because the favored color changes from position to position, token frequencies stay much closer to those of unwatermarked text than under a fixed green list. Detection needs only the text and the key, and it does not assume any unmasking order. On two masked-diffusion models, TANGO detects nearly all unedited watermarked texts and most edited ones, and frequency attacks that forge the fixed green list fail against it.

# TANGO 论文结构化总结

## 1. 核心问题与研究背景

- **研究动机**：语言模型生成文本已难以与人类写作区分，模型提供方需要识别自家模型产出的文本，文本水印因此成为关键技术手段。
- **核心矛盾**：绝大多数实用文本水印假定**从左到右的自回归生成**（如 Kirchenbauer 等的上下文哈希绿名单），每个词元与它之前的词元关联。但**掩码扩散语言模型（Masked-Diffusion LM）** 通过去噪循环并行、无固定顺序地填充掩码位置，在置信度解码下，某个位置被解掩码时，它之前的词元可能仍是掩码，导致上下文哈希无法计算。
- **现有方案的缺陷**：
  - **Gumbel 规则**（Aaronson, 2023）：可应用于每个去噪步，但若以前一词元为密钥，检测信号很弱——因为置信度采样器优先解掩码模型最有把握的位置，此时 Gumbel 规则倾向于选中同一词元，几乎不嵌入信号。
  - **固定红绿名单**（Zhao et al., 2024）：不需要上下文，可在扩散模型上原样运行，但在**每个位置都偏向同一批词元**，导致水印文本词频出现系统性偏移。攻击者通过比较水印/未水印文本的词频即可恢复绿名单，进而伪造出提供方检测器也能接受的文本，或去除水印。
- **核心需求**：论文提出三条要求——(R1) 无提示检测（仅用候选文本和密钥）；(R2) 顺序无关检测（不依赖解掩码顺序）；(R3) 频率隐藏的密钥（词频不应泄露密钥）。
- **整体含义**：TANGO 是首个专门为掩码扩散语言模型去噪循环设计、将水印信号嵌入**词元对（token pairs）** 的水印方案，在保持检测率与困惑度接近红绿名单的同时，使基于词频的密钥恢复与伪造攻击失效。

## 2. 方法论

### 2.1 核心思想

- 秘密密钥将词表划分为 q 个**近等大小（平衡）的颜色类**。
- 每个位置 i 与一个固定偏移 δ 处的词元（称为 **tap**）配对。当 tap 已解掩码时，TANGO 将 logits 偏向满足**校验和（checksum）** 的那一个颜色类。
- 水印信号是**二阶的**：来自词元对的颜色关系，而非任何单个词元。偏好颜色随位置变化，因此理想情况下无任何词元被平均偏向。

### 2.2 关键技术与公式

- **平衡着色（Balanced Coloring）**：每个颜色类含 ⌊V/q⌋ 或 ⌈V/q⌉ 个词元，使未水印文本满足校验和的概率接近 1/q。
  - **哈希着色**：对密钥伪随机排列分块，忽略语义，同义替换会随机化颜色。
  - **语义聚类着色**：平衡聚类嵌入，语义相近词元共享颜色，但小 q 时假阳性率远超标称值（q=2 时达 60%）。
  - **语义分位数着色（本文采用）**：按词元单位化嵌入在密钥方向 r_k 上的投影 ⟨e_v/‖e_v‖, r_k⟩ 排序，切成 q 个等量桶。同义词投影接近，替换后更可能保留颜色，且假阳性率接近标称值。

- **校验和（Checksum）**：设 χ: V → Z_q 为着色，a_δ ∈ Z_q\{0} 为 tap 系数，b 为目标余数：
  ```
  (χ(t_i) + a_δ · χ(t_{i−δ})) mod q = b
  ```
  一旦 tap 解掩码，恰好一个颜色类 s_i = (b − a_δ χ(t_{i−δ})) mod q 满足校验和。TANGO 对该类所有词元加偏置 β（LLaDA 上在 CFG 之后）。

- **双侧强制（Either-side Enforcement）**：若 gcd(a_δ, q)=1，方程也可对 tap 求解，因此当右邻 i+δ 已提交时，可将该位置偏向完成该对的颜色。多数对在采样器较晚提交的那一端被强制。默认单 tap D={2}，即偏移 2（跳过相邻词元，因相邻颜色相关性最强）。

- **检测**：检测器仅用文本和密钥，将文本重新着色，统计满足校验和的位置数 C：
  ```
  z = (C − T/q) / (√T · σ_0),  σ_0² = (1/q)(1 − 1/q)
  ```
  当 z 超过阈值 z* 时判定为水印文本。T 为计分位置数（仅取决于观测文本），因此满足 R2。

- **理论保证**：
  - **命题 1（二项零假设）**：在颜色均匀且与 tap 颜色独立、匹配事件相互独立的条件下，C ~ Binom(T, 1/q)，z 渐近 N(0,1)。
  - **命题 2（期望检测分数）**：E[z] = √T · ε/σ_0，ε 为耦合边际（coupling margin），即匹配概率超出 1/q 的平均值，检测所需文本量随 1/ε² 增长。
  - **定理 1（一阶不可伪造性）**：在采样理想化 (S)、不可预测性 (U) 和平衡 (B) 下，水印前后生成文本分布相同，E[Δf(v)]=0，任何按期望频率偏移排序的攻击者对颜色类的区分不超过随机（AUC=1/2）。
  - **定理 2（编辑鲁棒性）**：随机替换率 ρ 下，E[z_att] = (1−ρ)^{|D|+1} E[z_clean]，即每个额外 tap 都会使校验和更易被编辑破坏。

### 2.3 算法流程（文字说明）

1. 密钥构建平衡语义分位数着色 χ 一次。
2. 每个去噪步：对每个仍掩码的位置 i，若左 tap t_{i−δ} 已解掩码，则计算偏好类 s_i 并对该类 logits 加 β；否则若右邻 t_{i+δ} 已解掩码，则反向求解并偏向完成该对的颜色；两侧都掩码则不加偏置。
3. 按采样器常规规则采样候选并按置信度解掩码 K 个位置。
4. 检测：对每个 i > δ 计分位置，重新着色并检查校验和，计算 C 和 z，与阈值比较。

## 6. 主要结论与发现

- **检测性能**：TANGO 检测 **97%（LLaDA）/ 100%（Dream）** 的未编辑水印文本，编辑后为 **68–92% / 73–98%**，其中**删除是最难的攻击**。
- **文本质量**：困惑度 7.2（LLaDA）/ 7.8（Dream），与红绿名单的 7.6 / 9.1 相当；在 Dream 上红绿名单 62% 的文本退化为重复，而 TANGO 为 31%，未水印为 20%。
- **抗密钥恢复**：词频攻击对红绿名单的密钥恢复 AUC 从 25 条文本的 0.738 升至 100 条的 0.806，而对 TANGO 始终在随机水平（0.504/0.501）；TANGO 的词频总变差距离 0.217 接近有限样本噪声 0.210，低于红绿名单的 0.340。
- **抗伪造**：基于词频的伪造**全部通过红绿名单检测器，无一通过 TANGO 检测器**；基于词元对的攻击更困难（需估计 O(V²) 对频率），在 β_forge=4 时仅 4% 通过 TANGO 检测器，而 51% 通过红绿名单。
- **与已发表扩散水印对比**：DLM 水印和 dg
