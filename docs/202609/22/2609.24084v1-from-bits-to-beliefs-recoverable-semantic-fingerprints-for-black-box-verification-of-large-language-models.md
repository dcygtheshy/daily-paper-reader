## 摘要
开放权重的大语言模型（LLM）可被复制、修改并重新部署在黑盒 API 之后，这使得发布后的所有权验证变得困难。现有的黑盒指纹通常依赖能复现预定义响应的秘密查询-密钥对，因此很容易受到微调、剪枝、量化、模型合并以及服务时提示变化的影响。我们提出 SimPrint，一个用于黑盒 LLM 所有权验证的可恢复语义指纹框架。SimPrint 不依赖孤立的精确匹配，而是将私有所有者签名编码到编码语义指纹域中，把所有权证据分布到自然的二值问答探针中。它通过保持原始模型行为的低干扰批量更新，仅植入偏离基线的探针，随后利用纠错恢复机制将可疑模型的响应解析为可靠比特或擦除，从而恢复签名。由于验证仅使用输入-输出查询，当模型权重或激活不可访问时，SimPrint 仍然适用。在三个开放权重 LLM 上的实验表明，SimPrint 在干净和修改设置下都能可靠恢复所有者签名，在微调、剪枝、量化、模型合并以及服务时扰动下保持稳健，并维持相当的下游效用。

## Abstract
Open-weight large language models (LLMs) can be copied, modified, and redeployed behind black-box APIs, making post-release ownership verification difficult. Existing black-box fingerprints often rely on secret query-key pairs that reproduce predefined responses, and can therefore be easily disrupted by fine-tuning, pruning, quantization, model merging, and serving-time prompt changes. We propose SimPrint, a recoverable semantic fingerprinting framework for black-box LLM ownership verification. Rather than relying on isolated exact matches, SimPrint encodes a private owner signature into a coded semantic fingerprint domain, distributing ownership evidence across natural binary question-answering probes. It implants only base-deviating probes through a low-interference batch update that preserves the original model behavior, and later recovers the signature by parsing suspect-model responses into reliable bits or erasures with an error-correcting recovery mechanism. Because verification only uses input-output queries, SimPrint remains applicable when model weights or activations are inaccessible. Experiments on three open-weight LLMs show that SimPrint reliably recovers the owner signature in both clean and modified settings, remains robust under fine-tuning, pruning, quantization, model merging, and serving-time perturbations, and maintains comparable downstream utility.

- **研究背景**：大语言模型（LLM）的研发需要大量数据、预训练、对齐、评估与部署投入，模型权重已成为高价值知识产权。然而，开放权重与商业分发的 LLM 极易被复制、再分发、改编并集成到下游服务中，原始所有者几乎无法追踪。
- **核心问题**：模型窃取者可通过继续微调、剪枝、量化、模型合并等手段修改模型，并将其部署在黑盒 API 之后。此时所有者只能提交查询、观察响应，无法访问权重、激活、梯度或训练记录，传统的白盒参数级比对失效。
- **现有方法的缺陷**：主流黑盒指纹采用“查询-密钥对”范式，训练模型对少量秘密提示返回预定义响应。该范式依赖个别查询-响应之间的精确匹配，因此容易被系统提示、继续微调、剪枝、合并、量化等部署时修改破坏。
- **整体含义**：论文主张稳健的指纹不应依赖少数孤立查询-密钥对的存活，而应把所有权证据转化为**分布式、可恢复的身份信号**——每个查询看起来自然无害，响应整体却揭示一致的签名。

## 2. 方法论

### 2.1 核心思想

SimPrint 把黑盒 LLM 指纹重新定义为“从含噪语义响应中恢复结构化所有者身份”的问题，包含三个阶段：
1. 构造可恢复的语义指纹域（编码 + 自然二值问答探针映射）；
2. 通过低干扰批量编辑，仅植入必须偏离基线的探针行为；
3. 验证时查询可疑模型，将响应解析为比特或擦除，经纠错解码恢复注册令牌。

### 2.2 关键技术细节

**（1）编码语义指纹域**
- 所有者令牌表示为有限域 $\mathbb{F}_q = GF(2^\ell)$ 上的向量 $w = [w_1,\dots,w_m]$。
- 使用 Reed–Solomon（RS）码编码：$C = RS_{n,m}(w) = [c_1,\dots,c_n]$，附加 $n-m$ 个校验符号。
- 可纠正条件为 $2e + r \le n - m$，其中 $e$ 为错误符号数、$r$ 为擦除符号数。
- 码字展开为比特 $b \in \{0,1\}^N$，$N = \ell n$，每个比特对应一个自然二值问答探针。
- 秘密种子 $\kappa$ 决定探针采样、探针顺序、码字位置到探针的映射，以及平衡的保留/编辑掩码 $\rho \in \{0,1\}^N$。
- 探针被划分为 $S_{keep}$（保留基线答案）与 $S_{edit}$（需植入替代答案），两者数量近似相等。
- 通过秘密的候选答案到比特标签映射 $(Y_i^0, Y_i^1)$，使目标答案 $A_i$ 被解析为期望的编码比特 $b_i$。

**（2）选择性效用保持注入**
- 仅对 $S_{edit}$ 中的探针构造编辑。对每个编辑探针，提取可编辑层的输入激活作为键 $k_i$，期望输出方向 $v_i$ 由残差流上的短梯度搜索获得。
- 名义残差：$e_i = v_i - W_{base} k_i$。
- 利用从通用文本估计的主导激活方向 $U_{pre}$ 构造保持投影器 $P = I - U_{pre} U_{pre}^\top$。
- 堆叠编辑键与残差：$K_{edit} = \{k_i\}$，$E_{edit} = \{e_i\}$，投影键矩阵 $K_P = P K_{edit}$。
- 批量最小二乘更新：$\Delta\tilde{W} = E_{edit} K_P^\top (K_P K_P^\top)^\dagger$，最终扰动 $\Delta W = \Delta\tilde{W} P$，编辑权重 $W_{new} = W_{base} + \lambda \Delta W$。
- 该更新等价于将零空间约束编辑的一次性投影最小二乘适配，扩展到语义指纹注入。

**（3）黑盒验证与 RS 解码**
- 验证时用全部 $N$ 个探针查询可疑模型，匹配 $Y_i^0$ 解析为 0，匹配 $Y_i^1$ 解析为 1。
- 拒答、无关/畸形输出、不一致采样、模糊答案标记为擦除：$\hat{C} = [\hat{b}_1,\dots,\hat{b}_N]$，$\hat{b}_i \in \{0,1,?\}$。
- 每 $\ell$ 比特组合为一个 RS 符号，含擦除比特的符号标记为擦除，得到接收码字 $\hat{C}$。
- 恢复令牌 $\hat{w} = RSDecode(\hat{C})$，仅当解码成功且 $\hat{w} = w$ 时接受。
- **假阳性抵抗**：未签名基座模型在 $S_{edit}$ 上保留基线答案，被解析为注册比特的补码，产生符号错误；当 $2e_{base} + r_{base} > n - m$ 时被拒绝。默认配置下，无关模型的误接受概率上界约 $2.1 \times 10^{-33}$。
- **注册与抗歧义**：要求所有者在发布前对 $(w, \kappa)$ 做承诺并时间戳，防止事后挑选种子进行歧义攻击。

### 2.3 算法流程简述

1. 采样自然二值问答探针，确定基座稳定答案；
2. 将所有者令牌 RS 编码并展开为比特；
3. 按 $\kappa$ 分配保留/编辑掩码与候选答案标签；
4. 仅对编辑探针做投影最小二乘批量权重更新；
5. 验证时查询全部探针，解析比特/擦除，RS 解码恢复令牌。

## 3. 实验设计

- **模型**：Llama3-8B、Qwen3-8B、Llama3.2-3B 三个开放权重模型，覆盖不同家族与参数规模。
- **指纹配置**：$\ell = 8$，RS(24, 8) 码，$m = 8$ 字节令牌（如 "Verified"），64 位身份，$n = 24$ 符号，展开为 $N = 192$ 个二值语义探针。
- **探针来源**：按 CounterFact 记录格式构造，覆盖地理、宗教、体育等领域。
- **评估指标**：主指标为指纹成功率（FSR），即解码令牌与注册令牌完全匹配；辅以比特准确率（Bit Accuracy）与标准基准准确率。
- **模型变换场景**：
  - 指令微调：Alpaca、ShareGPT、Dolly；
  - 模型合并：DARE+TIES、TIES、DARE+Task Arithmetic、Task Arithmetic，多种合并比例；
  - 剪枝：随机剪枝与 Taylor 剪枝，比例 0.1–0.4；
  - 量化：GPTQ 4-bit 与 8-bit；
  - 服务时扰动：六种系统提示（Acknowledge、Advertise、Weather、Reason、English-only、Pirate）、回译复述、字符级拼写错误与同义词替换。
- **效用基准**：ARC、MMLU、HellaSwag、TruthfulQA、PubMedQA、GSM8K、OpenBookQA、PIQA、RACE 共九个基准。
- **对比基线**：Instructional Fingerprinting（IF）、Scalable Fingerprinting（SF）、CTCC、Semantically Conditioned Watermarks（RF）、iSeal，均按其原始验证协议评估。

## 6. 主要结论与发现

- SimPrint 在三个开放权重 LLM 上**干净设置下 FSR 达 100%**，未签名基座模型 FSR 为 0。
- 在**微调、模型合并、剪枝、量化、服务时扰动**下均保持 100% FSR，而多个基线在合并、剪枝等场景下显著退化甚至失效。
- **效用保持良好**：指纹化模型在九个基准上的平均准确率变化不超过 0.02，无系统性能力损失。
- **比特级分析**：合并比例扫描下比特准确率接近 1.0；剪枝比例增大时平滑退化而非骤降；量化后比特准确率仍高。
- **消融发现**：编辑强度 $\lambda$ 影响非单调——过小无法植入，过大扰动表示导致解码失败；即使 $\lambda = 50$ 时比特准确率仍 >0.90，但残差错误超出 RS 纠正能力，恢复失败。指纹长度扩展至 320 比特仍保持 100% FSR。
- **核心洞见**：稳健性来自“可恢复性”而非“精确存活”——只要全局编码响应模式仍可解码，个别探针失败可以容忍。

## 7. 优点

- **范式创新**：把黑盒指纹从“孤立查询-密钥精确匹配”转为“分布式编码语义信号的纠错恢复”，从根本上降低了对单点行为存活的依赖。
- **编码设计合理**：RS 码提供明确的纠错预算 $2e + r \le n - m$，并用擦除机制容忍拒答、模糊与畸形输出。
- **低干扰注入**：投影最小二乘批量更新将编辑限制在少数探针，并避开对普通行为重要的激活方向，效用损失极小。
- **纯黑盒验证**：验证仅需输入-输出查询，无需权重、激活或辅助模块，适用性强。
- **假阳性与抗歧义分析**：给出未签名模型拒绝的确定性条件与误接受概率上界，并提出时间戳承诺解决歧义攻击。
- **实验覆盖广**：三类模型、多类变换、多算法合并、多比例扫描，并同时报告端到端与比特级指标。

## 8. 不足与局限

- **算力信息缺失**：未报告 GPU 型号、数量、训练/编辑时长，可复现性与成本评估受限。

- **探针域限制**：探针为二值问答形式，依赖语义明确、候选答案稳定的场景；对开放式生成任务或主观问题的适用性未探讨。
