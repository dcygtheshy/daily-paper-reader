## 摘要
我们提出一种用于保护已训练神经网络的双重锁定方法，它将密钥驱动的索引置换与基于PIN的稀疏量化索引调制（QIM）水印相结合。通过独立地对自适应选择的索引向量的每一行施加均匀随机置换，引入密码学随机性。然后，通过调制偏置系数的量化值，将鲁棒盲二值水印嵌入偏置系数中，从而将网络与用户定义的个人识别码（PIN）绑定。在没有正确密钥的情况下，网络保留其架构，但由于内部表示被扰乱，其功能受损。逆置换可完全恢复原始模型精度，而嵌入的水印保持不可感知，并能够盲验证密钥关联和模型作者身份。为提高锁定有效性和可恢复性，一种自适应密钥选择策略将大幅值权重重新分配到低敏感位置，反之亦然，从而在保持完全恢复的同时增大锁定状态下的性能退化。在MNIST、CIFAR-10/100和ImageNet-1K上，使用全连接网络、ResNet CNN和Transformer架构进行的实验表明，锁定使准确率降至10%以下，对于CNN甚至低于0.5%，而正确密钥可完全恢复性能。水印不会引入可测量的准确率下降，并能可靠地验证所有权。对CNN和Transformer中嵌入分布的分析进一步表明，其对于识别训练不足或设计欠佳的模型具有潜在诊断价值。因此，所提方法同时提供了模型保护、恢复和所有权验证。

## Abstract
We present a dual-locking method for securing trained neural networks that combines key-driven index permutation with PIN-based watermarking based on Sparse Quantization Index Modulation (QIM). Cryptographic randomness is introduced by independently applying a uniform random permutation to each row of adaptively selected index vectors. A robust blind binary watermark is then embedded into the bias coefficients by modulating their quantized values, binding the network to a user-defined Personal Identification Number (PIN). Without the correct key, the network retains its architecture but becomes functionally impaired due to disrupted internal representations. Inverse permutation fully restores the original model accuracy, while the embedded watermark remains imperceptible and enables blind verification of key association and model authorship. To improve both locking effectiveness and recoverability, an adaptive key selection strategy redistributes high-magnitude weights to low-sensitivity positions and vice versa, increasing degradation in the locked state while preserving full recovery. Experiments on MNIST, CIFAR-10/100, and ImageNet-1K using fully connected networks, ResNet CNNs, and transformer architectures show that locking reduces accuracy below 10\%, and even below 0.5\% for CNNs, while the correct key fully restores performance. The watermark introduces no measurable accuracy degradation and reliably authenticates ownership. Analysis of embedding distributions across CNNs and transformers further indicates potential diagnostic value for identifying undertrained or suboptimally designed models. The proposed approach therefore provides simultaneous model protection, recovery, and ownership verification.

## 2. 方法论：核心思想与关键技术

- **总体框架**：双锁定 = **Stage 1 密钥驱动自适应索引置换锁定** + **Stage 2 基于 PIN 的稀疏 QIM 水印**。
- **网络形式化**：将各层权重矩阵和偏置向量展平、拼接为全局权重向量 \(w\) 和偏置向量 \(\bar b\)，并保存原始形状以便恢复。
- **基础索引置换锁定**：
  - 将密钥 \(K\) 哈希/扩展到权重向量长度。
  - 通过排序索引构造伪随机置换：\(\pi_K(i)=\arg sort(K)[i]\)。
  - 锁定权重为 \(W'=\pi_K(W)\)，解锁用逆置换 \(\pi_K^{-1}\) 恢复。
- **自适应索引置换**：
  - 按权重绝对值降序排序：\(L=\arg sort(-|w|)\)。
  - 取最大的 \(r\) 个高幅值权重索引 \(L_{hi}\) 和最小的 \(r\) 个低幅值权重索引 \(L_{lo}\)。
  - 分别对两组索引做均匀随机打乱，形成密钥矩阵 \(K=[shuffle(L_{hi}); shuffle(L_{lo})]\in\mathbb N^{2\times r}\)。
  - 交换高低幅值权重对，使短密钥也能显著破坏网络功能。
- **解锁机制**：只做逆置换，不改变权重数值，因此理论上可无损恢复原模型精度。
- **PIN 水印**：
  - 使用 QIM 标量量化器，将二值 PIN 水印嵌入偏置系数或权重系数。
  - 基本 QIM 通过两个均匀量化器 \(Q_0,Q_1\) 对系数做离散调制，量化步长为 \(\Delta\)。
  - 为降低功能失真，采用 **Sparse QIM**：每个水印比特分散到长度为 \(T\) 的参数段，通过固定单位投影向量 \(\varepsilon\) 投影到一维子空间后量化，再沿该方向回写。
  - 检测时对同一投影方向量化并恢复比特。
- **Transformer 适配**：
  - 主要锁定 embedding 张量，尤其 word embedding；列置换可破坏输出连贯性。
  - 位置 embedding 因维度小、密钥容量有限而被排除。
  - 锁定全部 embedding 比只锁 word embedding 略强，更快收敛到随机二分类基线。

## 6. 主要结论与发现

- **锁定效果显著**：
  - 自适应索引置换比随机置换高效得多，所需 key 长度小约一个数量级，优化网络甚至可小两个数量级。
  - 全连接网络锁定后准确率可降至约 10% 以下。
  - CNN 锁定效果更强，ResNet 等可降至 0.5% 以下甚至接近 0%。
- **可逆恢复**：
  - 使用正确密钥做逆置换后，模型可完全恢复原精度，无需额外微调。
- **水印影响可忽略**：
  - PIN 水印嵌入偏置系数后，准确率几乎不变，部分情况下甚至略有提升。
  - Sparse QIM 在微调后仍保持极低 BER 和 MSE，水印鲁棒性较好。
- **Transformer 表现**：
  - 锁定后准确率趋近 SST-2 的 50% 随机基线。
  - 归一化到随机猜测基线后，残余有效准确率低于 10%，可视为功能完全锁定。
- **诊断潜力**：
  - embedding 分布变化可能反映欠训练或次优设计。
- **参数选择启示**：
  - 偏置适合轻量 PIN 水印，不适合作为主要锁定对象。
  - 权重，尤其高幅值权重，更适合自适应置换锁定。

## 7. 优点

- **无损可逆锁定**：只置换索引、不改变数值，解锁后理论上完全恢复。
- **双机制互补**：功能锁定 + 所有权水印，分别应对未授权使用和版权验证。
- **自适应密钥选择**：优先扰动高影响权重，短 key 即可显著破坏模型功能。
- **Sparse QIM 设计合理**：将比特分散到多个载体，降低单点失真并提升抗
