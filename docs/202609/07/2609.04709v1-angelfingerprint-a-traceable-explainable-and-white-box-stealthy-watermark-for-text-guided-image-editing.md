## 摘要
文本引导的扩散编辑引发了虚假信息担忧，使得可靠的图像来源追踪至关重要。尽管水印常用于此目的，但大多数方法携带固定ID，无法解释修改了什么以及哪个提示词生成了它。此外，在开源白盒访问下，攻击者可以轻易定位并移除作为独立模块添加的水印。针对这一场景，我们提出了AngelFingerprint，一种新颖的水印框架，确保编辑可追溯性、可解释性和白盒隐秘性。它将LoRA集成到扩散模型中，将编辑提示词的CLIP文本嵌入直接嵌入模型权重。提取器随后仅从图像像素中恢复该嵌入。这种语义载荷解释了编辑内容，而权重集成设计使其即使在完全白盒访问下也难以检测和隔离。两项技术使这成为可能：一个保持编辑质量的速度对齐锚点，以及一个专门设计的频率滤波器，使水印不可感知但可恢复且稳健。在MagicBrush数据集上，我们的提取器在200路提示检索中实现了86%的top-1准确率，而提示反演仅为20%。

## Abstract
Text-guided diffusion editing raises disinformation concerns, making reliable image provenance essential. While watermarks are commonly used for this purpose, most methods carry a fixed ID that cannot explain what was changed and which prompt produced it. Furthermore, under open-source white-box access, attackers can easily locate and remove watermarks added as separate modules. Targeting this setting, we propose AngelFingerprint, a novel watermarking framework ensuring edit traceability, explainability, and white-box stealthiness. It integrates a LoRA into the diffusion model to embed the editing prompt's CLIP text embedding directly into the model's weights. An extractor then recovers this embedding from the image pixels alone. This semantic payload explains the edit, while the weight-integrated design makes it hard to detect and isolate even under full white-box access. Two techniques make this possible: a velocity-alignment anchor that preserves edit quality, and a specially designed frequency filter that keeps the watermark imperceptible yet recoverable and robust. On the MagicBrush dataset, our extractor achieves $86\%$ top-1 accuracy in a 200-way prompt retrieval, versus $20\%$ for prompt inversion.

  1. **可追踪性（Traceability）**：能追溯图像编辑的来源；
  2. **可解释性（Explainability）**：能揭示编辑操作内容与指令意图；
  3. **白盒隐秘性（White-box stealthiness）**：保持与原始模型完全相同的架构、计算和推理代码，使水印在开放权重下从根本上难以被定位和分离。

## 二、论文提出的方法论

### 1. 核心思想
- 将**编辑指令**（而非固定 ID）的 **CLIP-L 文本嵌入（768 维）** 作为水印载荷，通过 **LoRA** 直接写入扩散模型的 DiT（Diffusion Transformer）注意力投影矩阵权重中。
- 部署时模型与干净模型**结构完全一致**，没有额外模块、额外前向或异常分支；水印是“藏在权重里的隐蔽功能”。
- 单独训练一个**提取器 Eϕ**，它从编辑后图像的像素（经过固定频率滤波 H）直接恢复嵌入向量，再通过向量检索确定原始编辑指令。
- 选用 CLIP 嵌入而非离散文本的原因：SD3 的 DiT 内部只接收文本嵌入，若要嵌入离散 bit 串需额外模块，破坏白盒隐蔽性；离散文本不可微，无法与 LoRA/提取器端到端联合训练。

### 2. 训练目标（总损失）
联合优化 LoRA 参数 θ 与提取器参数 ϕ：

\[
L = \lambda_{fm} L_{fm} + \lambda_{embed} L_{embed} + \lambda_{ref} L_{ref}
\]

- **流匹配损失 \(L_{fm}\)**：保留 SD3 原生 rectified-flow 训练目标，保证生成能力不大幅退化。
- **嵌入恢复损失 \(L_{embed}\)**：由两项构成：
  - 余弦对齐 \(L_{cos}\)：拉近提取结果与目标提示嵌入的余弦距离；
  - 对称批内 InfoNCE \(L_{nce}\)：提供负样本对比，优化检索间隔（margin），防止嵌入坍塌到 CLIP 文本空间的狭窄锥形区域。
- **速度对齐锚点 \(L_{ref}\)（velocity-alignment anchor）**：将 LoRA 模型的**条件速度与非条件速度分别对齐**到无 LoRA 原始模型的对应输出（stop-gradient），数学表达式为：
  \[
  L_{ref} = \alpha \| v_{lora}^c - sg(v_{van}^c)\|_2^2 + \beta \| v_{lora}^u - sg(v_{van}^u)\|_2^2
  \]
  其中非条件分支权重更高（β>α），因为它对图像保真度影响最大；对齐“四个点”（条件/非条件 × 模型）而不是仅对齐 CFG 引导后的合成速度，可保证模型在任意引导强度下都不漂移。

### 3. 频率滤波器（核心设计之一）
- 在生成图像与提取器之间插入一个**固定 JPEG 风格 DCT 带通掩码**：只保留 8×8 块内中频带系数（\(4 \le i+j \le 7\)，共 26/64 个系数），低/高频系数在前向与梯度更新中都被阻断。
- 这一设计同时带来四重收益：
  1. **稳定训练**：避免低频语义重建损失与水印嵌入梯度方向冲突导致的不收敛；
  2. **防止捷径**：迫使提取器无法从图像内容（集中于低频）猜测提示词，只能真正解码水印信号；
  3. **不可感知性**：LoRA 在可见的低频区得不到任何收益，水印被自然地驱赶到感知不敏感的中频带；
  4. **鲁棒性**：抛弃易被 JPEG/重采样破坏的高频区，使水印天然匹配 JPEG 压缩保留的系数范围。

## 三、实验设计

### 1. 数据集与评测基准
- **数据集**：MagicBrush（人工标注、多轮指令编辑数据集，源图来自 MS-COCO），每轮为（源图，指令，掩码，目标图）的一条独立编辑记录。

## 六、论文的主要结论与发现

- 在 SD3-medium 上，AngelFingerprint 的提取器在 200 路提示检索中达到 **Top-1 86.0%、MRR 0.917、恢复嵌入与真实提示余弦相似度 0.802**；最优提示反演基线仅在 Top-1 取得 22.5%，且对未加水印图像的增益为负——证明水印信号是恢复的唯一来源（ΔTop-1 = +0.860）。
- 在 UltraEdit-SD3 上也达到 **Top-1 65.5%**，说明方法对编辑专用微调主干可迁移。
- 水印对编辑结果视觉影响极小：与 LoRA 关闭相比 DreamSim ≈ 0.221、LPIPS ≈ 0.299、SSIM ≈ 0.704；相对真实图片的 FID ≈ 132–165，明显优于所有无滤波器的消融变体。
- 鲁棒性方面：对 JPEG 压缩（Q≥30）、裁剪（无缩放）、中等高斯噪声与色彩失真均保持高检索率；但对**缩放/重采样非常脆弱**（Top-1 降至 1% 左右），因缩放会破坏 8×8 DCT 块的同步性；对权重级攻击具有较好韧性：int8 量化几乎无损失（Top-1 86%），50 步微调后仍保持 Top-1 84%，300 步微调后仍显著高于随机水平。
- 水印存在性可用提取器输出的 L2 范数直接判别：水印图像（均值≈40.3）与 LoRA-off 图像/自然照片（均值≈7）完全分离，AUC 达到 1.000。
- 开集部署中，水印嵌入具有语义可读性——真实编辑语句与近似释义分数高，无关语句分数低，证明验证者可借助 VLM 生成候选句进行溯源。

## 七、优点

1. **问题定义清晰新颖**：首次系统性地把“可追踪 + 可解释 + 白盒隐秘”三者统一为一个水印问题，并指出现有方法（AquaLoRA 等）只满足其中部分属性。
2. **权重集成式水印设计**：仅改变权重数值，不引入额外模块或计算，模型发布形式与普通微调模型完全一致，是真正意义上的白盒隐蔽。
3. **编码语义载荷而非固定 ID**：利用流匹配模型天然接收 CLIP 文本嵌入的特点，实现无需额外文本注入架构的可微端到端训练，且恢复结果具有可解释性。
4. **两个关键技术互补**：频率滤波器（规定水印在频谱中的位置），速度对齐锚点（约束模型输出漂移），一个管“空间”，一个管“幅度”，在不可感知性与可恢复性之间取得了良好平衡而非简单折衷。
5. **InfoNCE 用于水印训练的洞察**：指出仅使用余弦对齐会造成嵌入坍塌到 CLIP 文本嵌入的狭窄锥形区域；批内对称 InfoNCE 直接优化检索间隔，有效避免了这一问题。
6. **实验设计细致**：几乎所有评估都区分“水印贡献”与“图像内容贡献”（LoRA 开/关对照、Δ 增益），保证了测量的是水印本身而非自然图像-文本关联；消融充分，验证了每个组件的必要性。

## 八、不足与潜在改进方向

1. **鲁棒性的结构性短板：缩放与重采样攻击几乎失效**
   - 论文明确承认：任何涉及图像重采样的操作（包括简单 resize、放大后再裁剪等）都会破坏 8×8 像素块与 DCT 系数坐标之间的对齐假设，导致提取器完全无法定位水印。Top-1 从 86% 骤降至 1% 左右。
   - 根本原因是频率滤波器基于“固定的 JPEG 块网格”设计，而非尺度不变或几何对齐的特征。改进方向可以是：将水印嵌入在 DCT 系数的相对统计量上（而不是绝对块位置），或在训练时加入随机重采样/仿射变换的数据增强，使提取器学会从任意网格位置恢复信号；但后者可能会牺牲一定的白盒隐秘性，因为需要提取器更复杂的架构。
   - 对实际部署而言，社交平台几乎必然对上传图片做重新压缩或尺寸调整，因此这一缺陷可能严重制约真实场景可用性。

2. **语义载荷带来的容量与精度折衷**
   - 使用 CLIP 嵌入作为水印信号，本质上是“在连续向量空间中嵌入一个点”，最终需要通过检索（retrieval）映射回文本。这要求验证者必须拥有一个包含原指令（或相近释义）的候选池；如果用户从未见指令进行编辑，水印只能恢复“语义相似”的向量，而无法精确恢复原始字符串。
   - 论文的开集实验使用的是人工生成的候选句，若攻击者刻意改写指令（如将“把狗变成猫”改为“把狗替换成毛茸茸的小猫”），水印能保持多大语义一致性仍未系统测试。理想方案可能是结合语义哈希或码本量化，但需要额外的解码模块，可能损害白盒隐蔽性。

3. **防移除能力仅测试“良性”微调**
   - 权重级攻击只考虑了继续用编辑数据做少量微调（最多 300 步）以及普通精度量化。没有测试更有针对性的水印移除手段，例如：
     - 使用 LoRA 的“权重剪枝 + 微调”（pruning + fine-tuning）；
     - 知识蒸馏（将水印模型蒸馏到未加水印的干净模型）；
     - 模型融合/权重平均（与多个干净模型平均，稀释 LoRA 信号）；
     - 对抗性重训练（已知水印存在，专门设计损失阻止提取器读取）。
   - 这些攻击在 open-weight 场景下都是现实可行的。论文只证明“常规操作不会轻易破坏水印”，而未证明“恶意用户无法定向移除”，这距离强白盒鲁棒性仍有差距。

4. **实验域单一：仅覆盖 SD3 架构**
   - 虽然验证了 SD3-medium 与 UltraEdit-SD3，但两者本质上都是同一 DiT/MMDiT 架构（UltraEdit 只是在 SD3 上微调）。没有实验支撑该方案能否迁移到其他主流编辑模型（如基于 UNet 的 InstructPix2Pix、基于 DiT 的 PixArt 之类的模型），也没有在非编辑生成任务（如文生图）上验证。
   - 频率滤波器的设计（DCT 块大小 8×8）取决于生成图像的分辨率和压缩习惯，对不同分辨率的适用性（如 1024×1024 或非 8 的倍数尺寸）需要更多测试。

5. **提取器 Eϕ 本身的安全性问题**
   - 论文将提取器视为“发布方可私藏的验证工具”，但假设了攻击者无法获取提取器。如果攻击者拿到了提取器，就可以：
     - 用其作为判别器，对大量候选图片做水印存在性检测，从而筛选出包含水印的模型生成图；
     - 通过白盒攻击（对提取器输入求梯度）在像素域制造对抗扰动，使提取结果偏离真实嵌入，从而既破坏溯源又导致误判；
     - 直接用提取器输出作为“解码器”，反向训练一个移除器来从模型中擦除该语义信号。
   - 论文对提取器本身的安全模型没有讨论，也没有提出保护措施（如限于离线使用、加密或混淆）。

6. **对“水印所有权证明”的潜在逻辑漏洞**
   - 论文声称水印对编辑来源具有可追踪性，但水印只嵌入在“模型权重”中。若发布方在多个模型副本中均使用相同 LoRA，则所有模型生成的编辑图像都携带同一种“来源标签”，无法区分是哪一次发布、哪个用户下载后产生的。文中没有讨论“多接收者溯源”（collusion-secure fingerprinting）场景。
   - 更关键的是，如果发布方在后续更新模型时继续使用同一 LoRA 载体，攻击者可以对比新旧权重，通过相减提取出 LoRA 权重并直接移除；在开放权重环境下这种差分攻击成本极低。

7. **客观实验条件偏单一**
   - 所有实验只在一块 GPU 上顺序完成，没有报告多次随机种子的方差。考虑到训练 30 epochs 需 40 小时，损失的随机性可能对最终检索率产生不小影响，但文中没有给出标准误或多次重复实验的结果；这降低了结论的统计稳健性。

## 九、总结与启示

AngelFingerprint 在概念层面做出了一个值得重视的推进：它证明了“可解释的水印”可以不依赖任何额外模块，而仅靠修改模型内部权重（LoRA）实现。这种思路在开放权重生态中有明确的应用价值——它意味着模型发布者可以“无声地”在权重中嵌入一个语义记录器，而无需改变用户获得模型的方式。与此同时，它也清晰地暴露了权重级水印在对抗性环境中的边界：缩放攻击、提取器泄露、定向微调都仍可能彻底破坏溯源能力。

从研究脉络看，该工作的对比对象已不再是传统图像水印，而是“可与模型权重融为一体、同时保留语义感知的隐藏能力”。这启发未来研究可沿三个方向继续深入：
1. **尺度/几何不变的频谱水印**：摆脱对像素块网格的依赖，让水印能够抵抗任意重采样，甚至能像 DNN 水印一样在 latent space 中保持相关性；
2. **可证明的安全性**：将水印设计为密码学意义上的“不可移除”属性（在给定计算能力边界下），或至少明确刻画其安全模型（如“诚实但好奇”的验证者、“恶意”的重训练者）；
3. **多接收者指纹与差分隐私**：在 LoRA 权重上叠加独立随机扰动，实现同一模型向不同用户的“个性化水印”，同时保持生成质量，从而能在多个发布副本之间做唯一性溯源。

总体而言，这是一篇问题清晰、方法有洞察力、实验较扎实的有价值研究，但距离“实际部署中的鲁棒溯源”仍有关键一步未跨过。最值得我注意的，并非它获得了多高的 Top-1，而是它提供了一个思想上极为优雅的转变——水印不只是被“加入”到模型中，而是被“调制”进了模型的参数语义空间，成为其“内隐知识”的一部分。
