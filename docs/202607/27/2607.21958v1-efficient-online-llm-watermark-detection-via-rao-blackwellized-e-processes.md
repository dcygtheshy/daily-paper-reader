## 摘要
随着大语言模型（LLMs）的日益部署，可靠且高效的机制来区分AI生成文本与人类撰写内容变得至关重要。统计水印已成为一种有前景的解决方案，然而，大多数现有方法通常是固定视界程序，无法在流式生成中进行有效的早期停止。在本文中，我们开发了一个高效的在线水印检测框架，基于Rao-Blackwellized E-过程实现任意有效推断，使得能够在无需存储完整历史的情况下进行递归的令牌级证据更新。特别地，我们针对Gumbel最大水印实例化了该框架，并将原始的令牌级依赖检验问题简化为一个具有显式零分布的枢轴量诱导的序贯检验问题。理论上，我们证明了在任意可选停止下的任意有效第一类错误控制，并建立了水印下的正渐近对数增长，这意味着所提出的停止规则的一致性。在真实LLM生成文本上的模拟和实验展示了具有严格任意有效保证的高效在线检测。

## Abstract
As large language models (LLMs) are increasingly deployed, reliable and efficient mechanisms for distinguishing AI-generated text from human-written content have become essential. Statistical watermarking has emerged as a promising solution, yet most existing methods are typically fixed-horizon procedures, precluding valid early stopping in streaming generation. In this paper, we develop an efficient online watermark detection framework with anytime-valid inference based on Rao-Blackwellized e-processes, enabling recursive token-level evidence updates without storing the full history. In particular, we instantiate the framework for the Gumbel-max watermark and reduce the original token-level dependence testing problem to a pivot-induced sequential testing problem with an explicit null distribution. Theoretically, we prove anytime-valid Type I error control under arbitrary optional stopping and establish positive asymptotic log-growth under watermarking, implying consistency of the proposed stopping rules. Simulations and experiments on real LLM-generated text demonstrate efficient online detection with rigorous anytime-valid guarantees.

## 2. 方法论：核心思想与关键技术细节

### 核心思想
论文提出基于 **Rao–Blackwellized e-processes** 的在线水印检测框架。核心思路是将原问题从“全数据依赖”转化为**基于枢轴量（pivot）的简化序贯检验**，从而仅需维护低维充分统计量即可递归更新证据，无需存储完整历史。

### 关键技术细节
- **枢轴量定义**：针对Gumbel-max水印，定义枢轴量 \(Z_t = -\log(1 - U_{t,W_t})\)，其中 \(U_{t,w}\) 是均匀随机变量。在零假设（无水印）下，\(Z_t \sim \text{Exp}(1)\)，分布完全已知。
- **E-过程构造**：采用指数型得分函数构建单步e值 \(E_t(\lambda) = (1-\lambda)e^{\lambda Z_t}\)，累积乘积得到 e-过程 \(M_t(\lambda) = \prod_{s=1}^t E_s(\lambda)\)。理论证明其在零假设下为有效e-过程，满足任意停止下的Type I错误控制（Ville不等式）。
- **参数选择策略**：
  - **固定参数法**：固定 \(\lambda \in (0,1)\)。
  - **自适应插件法（Plug-in）**：在线估计均值 \(\hat{\mu}_{t-1}\)，设置 \(\lambda_t = \text{clip}(1 - 1/\hat{\mu}_{t-1})\)。
  - **混合法（Mixture）**：对多个候选\(\lambda\)加权平均，以凸组合保持有效性。
- **简化解释**：通过构建替代指数族（surrogate reduced family），证明累积枢轴和 \(S_t = \sum_{s=1}^t Z_s\) 是充分统计量，从而Rao-Blackwell化原理保证了e-过程的最优性。

### 算法流程（文字说明）
1. 初始化 \(M_0 = 1\)，输入显著性水平 \(\alpha\) 和参数 \(\lambda\)（或自适应混合策略）。
2. 对每个新令牌 \(w_t\)：
   - 根据密钥重构伪随机变量 \(U_{t,w_t}\)。
   - 计算枢轴 \(Z_t = -\log(1 - U_{t,w_t})\)。
   - 计算单步e值 \(E_t\)，更新 \(M_t = M_{t-1} \times E_t\)。
   - 若 \(M_t \geq 1/\alpha\)，则在t时刻拒绝零假设并停止；否则继续。
